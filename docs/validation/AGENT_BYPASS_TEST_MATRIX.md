# AXIOM 1.0 — Phase 3: Agent Protection Bypass Test Matrix

> **Baseline:** `v0.32.0` + post-release hardening (`main` working tree)  
> **Scope:** Isolated, non-destructive security & bypass matrix across supported AI agent host adapters (`OpenCode`/`OpenChamber`, `Claude Code`, `Codex`, `Antigravity`, etc.) and `Axiom.Core.Enforcement` (`EnforcementPolicyEvaluator`, `TrustedFileBroker`).  
> **Non-negotiable rule:** Cooperative host hooks are `HostHook` controls, not `OsBoundary` controls. When a host does not honor a hook (e.g., Codex untrusted hash, child process spawned outside the hook, or guard runtime crash triggering fail-open `GUARD_FAILED`), Axiom must never report `OS_DENY_VERIFIED`.

## 3. Defects Fixed & Remaining Follow-Ups from Phase 3

1. **Fixed `#275` (`src/Axiom.Presentation/AntigravityProtection.cs`, `src/Axiom.UI/Services/AntigravityProtection.cs`):** Windows `%LOCALAPPDATA%` paths with spaces/metacharacters now generate a BOM-free `axiom-antigravity-hook.cmd` wrapper invoked via caret escaping in `hooks.json` (zero `"` characters preserved for Go `exec.Command("cmd", "/c", ...)` compatibility), plus automatic detection & repair of legacy broken space-split entries.
2. **Fixed traversal bypass in `EnforcementScopeMatcher` (`src/Axiom.Core/Enforcement/EnforcementPolicy.cs`):** Normalized `.` / `..` path segments stack-wise and stripped Win32 `//?/` / `//./` prefixes so `C:\work\..\secrets\token.txt` and `\\?\C:\secrets\token.txt` match `ProtectedResource` rules and cannot hijack sibling `Allow C:\work` rules.
3. **Open VM Follow-Ups (Phase 3 / 4 live Windows sandbox needed for runtime-only proofs):**
   - Execute live host-CLI smoke runs (Codex after trust approval, Claude Code, OpenCode, Antigravity) inside an isolated Windows sandbox VM with synthetic `.env`/mnemonic fixtures to upgrade `UNVERIFIED_RUNTIME` rows to `HOST_DENY_VERIFIED`.
   - Document same-user cooperative-hook tamper boundaries clearly in `docs/SECURITY_MODEL.md` (already aligned with Phase 3 & `AGENTS.md` architecture notes).
