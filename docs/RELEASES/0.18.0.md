# Axiom 0.18.0

**Released:** 14 November 2026

0.18.0 introduces reputation-safe Threat Share orchestration (#321) and curator-signed verified-graph snapshot distribution (`VerifiedGraphPeerRelay`), preventing noisy or speculative reports from harming Blackbox reporter standing.

## Highlights

- **Reputation-safe Threat Share models and anti-rejection rules (#321, `21ebe68`).** Strict `ThreatShareModels`, AI process evidence provenance, and eligibility gating reject ambiguous or private-only indicators before CLI submission.
- **DNS-to-process correlation and IOC extraction (#321, `3a909cc`).** `DnsProcessCorrelator` and `ThreatShareCandidateExtractor` link suspicious remote destinations to local DNS lookups and owning processes.
- **Pre-flight novelty checks, simulation CLI & retract lifecycle (#321, `8e15030`).** Bounded local pre-flight novelty checks (`ThreatShareCli` simulation/retract) classify `Potentially new`, `Already known`, or `Unknown` against the local verified graph before publishing.
- **Curator-signed RAM snapshot endpoint & opt-in LAN cache (`67cf732`).** `VerifiedGraphPeerRelay` enables verified-graph RAM distribution on opt-in LAN peers without opening unauthenticated outbound sharing.

## Verification

- `dotnet test Axiom.sln --nologo` passed across all core, contracts, presentation, service, persistence, MCP server, Infrastructure.Windows, WPF UI, and Avalonia UI suites (0 failures, 0 skipped).
- Dedicated regression tests added for `ThreatShareEligibility`, `DnsProcessCorrelator`, `ThreatShareCandidateExtractor`, pre-flight retract flows, and `VerifiedGraphPeerRelay`.

## Upgrade notes

Install over 0.17.0 as usual; community sharing and Threat Share publishing remain strictly opt-in and off by default.
