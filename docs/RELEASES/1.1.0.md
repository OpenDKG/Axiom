# Axiom 1.1.0

**Released:** 17 November 2026

## Mini mode stays inside its fields when the window shrinks

1.0.0 added the Module Health strip to Mini mode and let the throughput chart take the remaining
height. At the minimum window size that star-sized row could not shrink below its minimum and drew
over the activity card.

- The Mini content is now inside a `ScrollViewer`: every field keeps its own place, and a window
  too short for everything scrolls instead of overlapping.
- The throughput chart is a fixed, compact 72 px again; the Module Health strip keeps its row.
- At the normal 820x640 the content fits without a scrollbar; smaller windows compact by scrolling.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed in the VM and resized to 780x460: Module Health, throughput and Agent Activity no longer
  overlap; the layout scrolls when needed.
- Windows CI build, tests and packaging check pass.
