# Axiom 0.10.5

**Release date:** 2026-11-10

Grouped blocked-query history, and a safety fix for the DNS outage where an adapter still pointed at a
stopped resolver.

## Blocked query history

- The retained history is grouped **by application**: one expandable row per app with its block and
  domain counts and last time.
- Opening an app lists every blocked domain for it with category, count, last time and the same
  **Allow** / **Block** actions; both act on that domain's latest event.
- The list scrolls inside its card instead of growing the page.

## Resolver outage safety

The LAN outage on 10 November happened because Privacy Shield was disabled while the Ethernet adapter
still had DNS `127.0.0.1`. With nothing listening, every name lookup on that adapter failed.

- Axiom now refreshes the adapter list from the real DNS state and, when any adapter still points at
  `127.0.0.1` while the resolver is not running, shows a warning in the Adapter DNS card and raises a
  forced alert that opens the Privacy Shield page.
- Pointing an adapter at the resolver was already refused while the resolver was stopped; the
  restore-saved-DNS action remains available.
- The affected adapter was restored to DHCP (`192.168.0.1`) and the Wi-Fi adapter was left untouched.

## Verification

- `dotnet build Axiom.sln`: 0 warnings, 0 errors.
- `dotnet test Axiom.sln`: 468 passed, 0 failed.
- Network state after the fix: Ethernet DNS `192.168.0.1`, Wi-Fi DNS `192.168.1.1`, name resolution
  working on both.
