# Axiom 0.14.0

**Release date:** 2026-11-12

This is a focused UI/layout release on top of the 0.13.x reliability line. It changes where
information appears, not how protection, DNS or firewall enforcement behaves.

## Highlights

### Dashboard hierarchy

- **System status moved to the page header.** The full-width System status card is gone from the
  Dashboard; the same status text now sits in the header between the page title and the theme
  selector.
- **Agent activity above throughput.** The Agent activity card now appears before the
  System-wide throughput chart, so recorded agent sessions and findings are the first detailed
  section.
- **Compact KPI row.** Active sockets, Processes, Loopback and Throughput use tighter padding,
  smaller value type and shorter accent bars, reducing the visual weight of the counter row.

### Protection navigation

- The PROTECTION group now reads **Agent Protection → Agent Activity → Network Control → Privacy
  Shield**, with the group header starting on Agent Protection.

### Rollup

- Includes the 0.13.2 reliability fixes (AI Analyst API-key handling, live history `last_seen`,
  Events filter race handling, evidence tail reads, OpenCode bridge child-process errors).
- Includes the 0.13.x Antigravity UI/theme work and the 0.12.0 service-owned network recovery and
  enforcement foundation.
- No new firewall, DNS, agent-hook or publishing behavior is introduced by this release's layout
  changes.

## Verification

- `dotnet build Axiom.sln -c Release`: 0 warnings, 0 errors.
- `dotnet test Axiom.sln -c Release`: 725 passed, 0 failed across all 9 test projects.
- The headless Avalonia test renders `MainWindow` and navigates every page without a render error.
- Release artifacts are built by `scripts/build-release.ps1`; checksums are published in
  `SHA256SUMS.txt`.

### Not verified in this release

- Live/elevated DNS or firewall restore and the full Windows 10/11 VM matrix remain explicit
  verification gates; this release does not claim they passed.
- The portable artifacts are unsigned; Windows SmartScreen may warn. Verify the published
  `SHA256SUMS.txt` and compare it with the release assets. #119 tracks signing.

## Compatibility and rollback

- Windows 11 x64 is the primary target; Windows 10 x64 is best-effort.
- Portable desktop/service are self-contained; no .NET runtime is required.
- To roll back the application, stop the service, deploy the previous build and start it again.
  Do not remove firewall rules by prefix and do not delete the history database as a rollback step.
- Linux and macOS are not part of this release.

## Artifacts

- `Axiom-Setup.exe` — self-contained per-user setup with embedded desktop and service.
- `Axiom-0.14.0-win-x64.zip` — portable archive.
- `SHA256SUMS.txt` — SHA-256 for the setup and archive.
