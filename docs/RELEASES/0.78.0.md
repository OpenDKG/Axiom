# Axiom 0.78.0

**Released:** 16 November 2026

## Setup automatic shutdown, install/update, relaunch, and exit

- Both **Install** and **Update** flows (as well as `--silent` CLI installs/upgrades) in
  `SetupNativeWindow` and `SetupInstaller.InstallAsync` now close any running `Axiom.Desktop`
  process cleanly without displaying an `"Axiom is running"` prompt or failing with a running-process
  error.
- Once installation or in-place upgrade finishes, Setup automatically launches the installed Axiom
  desktop application and closes the installer window.
