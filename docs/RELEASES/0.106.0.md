# Axiom 0.106.0

**Released:** 17 November 2026

## New titanium brand icon everywhere, and partner logos that fill their plates

### Axiom icon and lockup

The new titanium artwork from the design folder replaces the old assets across the app:

- `axiom-icon.png` (1254x1254) — window icon and taskbar, the title bar, the Mini header, toast
  notifications and the first-run dialog.
- `axiom-lockup.png` (shield + AXIOM) — the sidebar lockup and the first-run dialog.
- `axiom.ico` was regenerated from the new icon as a multi-size icon (16–256 px) for the desktop,
  service setup and Start Menu shortcuts, so Explorer/taskbar no longer show the old mark.
- The WPF fallback resources were updated with the same two PNGs.

### Partner logos

The previous change enlarged the image *box*, but `Stretch="Uniform"` letterboxed the 3:1 logos
inside it, so the dark plate behind each logo stayed wider than the visible mark.

- The image now sets only a height: OriginTrail 56, Blackbox 34, Umanitek 44.
- The plate padding is 6,4 and its width comes from the image, so the background follows the logo
  instead of framing empty space.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- The regenerated `axiom.ico` loads as a valid icon; window/taskbar use the new PNG.
- Installed in the VM and inspected: new Axiom mark in the title bar, sidebar and taskbar; the three
  partner logos are larger and their plates hug them.
- Windows CI build, tests and packaging check pass.
