# Axiom 0.34.0

**Released:** 15 November 2026

0.34.0 closes the credential-access, defence-evasion, persistence and execution gaps found in the
second half of the attack-vector sweep (65+ tool calls through the installed guard bridge in the
Windows 11 lab VM).

## What was allowed before

| Family | Examples that passed |
| --- | --- |
| Credential access | `reg save HKLM\SAM`, `reg save HKLM\SECURITY`, `vssadmin create shadow`, `ntdsutil ifm`, `procdump -ma lsass`, comsvcs `MiniDump`, `wevtutil cl Security` |
| Defence evasion | `Set-MpPreference -DisableRealtimeMonitoring`, `Add-MpPreference -ExclusionPath`, `netsh advfirewall set allprofiles state off` |
| Persistence | `Register-ScheduledTask`, `New-ItemProperty …\Run`, `sc create`, copy into the Startup folder |
| Execution | `wmic process call create`, `IEX …DownloadString`, `Add-Type -TypeDefinition`, `wscript payload.vbs`, `mshta vbscript:` |

## Fixes

`AgentCommandGuard._escalation_risk` (shared by all nine host adapters and the OpenCode bridge) now
returns a named vector for:

- `credential hive export` — `reg save` on SAM/SECURITY/SYSTEM
- `shadow-copy creation`, `NTDS dump`, `LSASS memory dump` — vssadmin/ntdsutil/procdump/comsvcs
- `event log clearing` — `wevtutil cl` / `Clear-EventLog`
- `Defender tampering` and `Defender exclusion` — `Set-MpPreference` disable flags, `Add-MpPreference -ExclusionPath`
- `firewall tampering` — `netsh advfirewall … state off`, `netsh firewall … opmode disable`
- `scheduled-task persistence (PowerShell)`, `registry run-key persistence (PowerShell)`,
  `service creation`, `startup folder persistence`
- `WMI process creation`, `download-and-execute`, `in-memory compile`,
  `script host execution` (wscript/cscript + .vbs/.js/.wsf), `mshta vbscript`

All checks run before the vendor guard, so a missing verified rule cannot let the shape through.
Plain `curl https://…/api/health`, `git status`, `dotnet build` and the allowed self-test write
still pass.

## Verification

- `dotnet build Axiom.sln --nologo` — 0 warnings, 0 errors across 21 projects.
- `dotnet test Axiom.sln --no-build --nologo -m:1` — **1008/1008** passed.
- Lab VM with the 0.34.0 bridge, 23/23 vectors:
  - 4 controls (`echo`, `git status`, `dotnet build`, plain HTTPS GET) → **allow**;
  - 19 attack shapes above → **block** with the named vector.
