# Axiom 0.43.0

**Released:** 15 November 2026

0.43.0 adds the audit sink for F-19: the service-side handler needs a concrete destination, and this
one writes one JSON line per recorded spawn to an injected writer.

## What this adds

- `JsonLinesProcessSpawnSink` (`src/Axiom.Core/Enforcement`):
  - implements `IProcessSpawnAuditSink`;
  - writes `timestampUtc`, `pid`, `parentPid`, `image`, `parentImage`, `verdict` (`block`/`record`)
    and `reason` as one compact JSON line per row, then flushes;
  - the writer is injected, so the service owns the file path and retention while Core stays
    testable and file-policy free.

## Verification
