# Axiom 0.76.0

**Released:** 16 November 2026

## Blackbox local ruleset streaming and cache

Axiom no longer reads and parses the full `ruleset.json` DOM into memory at startup and on every
8-second / 60-second Agents refresh tick.

- Replaced `File.ReadAllText` + `JsonNode.Parse` in `BlackboxLocalState` (`src/Axiom.Presentation`
  and `src/Axiom.UI/Services`) with a single-pass `Utf8JsonReader` over a `FileStream` and pooled
  `64 KB` buffer (`ArrayPool<byte>`), including UTF-8 BOM handling and strict root validation.
- Added bounded sample collection in `TryReadGraph` (`MaxGraphThreatsSample = 256`,
  `MaxCategoryArraySample = 80`, `MaxCategoryMapSample = 12`) while preserving exact category and
  rule counts across large collections.
- Added a bounded snapshot cache keyed by `(Length, LastWriteTimeUtc.Ticks)` so unchanged
  `ruleset.json` files incur zero re-reads across timer ticks, `EvaluateContinuity`, `TryReadSync`,
  `TryReadGraph`, and `DkgContextAnnotator.LoadFromLocalCache`.
- Updated `ProtectionProvisioner.ProvisionAtStartup` to call `BlackboxLocalState.HasVerifiedRulesFile`
  instead of reading the entire ruleset string into memory on desktop startup.

## Simple View: AI Agent Guard and live Agent Activity

- Added an **AI AGENT GUARD** summary card and an **AI agent activity right now** live feed side
  by side with **Apps using the internet right now** in `SimpleHomeView` / `SimpleHomePageViewModel`.
- Simple Mode now activates `Agents` for live updates without technical jargon, with an
  **Open Agents** shortcut to jump straight into Advanced `Agents`.

## Setup in-place Update auto-close & relaunch

- In-place updates in `SetupNativeWindow` and `SetupInstaller.InstallAsync` no longer prompt or
  abort with `"Axiom is running"`.
- Setup automatically closes any running `Axiom.Desktop` process cleanly, performs the update,
  relaunches Axiom, and exits Setup automatically when finished.

## Enforcement controller status provisioning fix

- `EnforcementController` now runs machine-default policy provisioning only when instantiated via the
  service's parameterless constructor, keeping explicit policy-path callers disabled when their
  target file does not exist (`EnforcementControllerTests.Missing_policy_file_is_disabled_and_returns_unavailable`).
