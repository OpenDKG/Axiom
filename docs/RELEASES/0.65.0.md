## Guard self-protection

A 20-probe tamper batch on the 0.64 hooks found nine allowed shapes that disable or blind the guard
(issue #384):

| Probe | Payload | Now |
| --- | --- | --- |
| Stop the service | `powershell -c "Stop-Service Axiom -Force"` | tamper block |
| Stop the service | `sc stop Axiom` | tamper block |
| Kill the service | `taskkill /f /im Axiom.Service.exe` | tamper block |
| Kill the desktop | `taskkill /f /im Axiom.Desktop.exe` | tamper block |
| Delete the evidence log | `del …\Axiom\agent-evidence.jsonl` | tamper block |
| Re-ACL the Axiom tree | `icacls …\Axiom /grant Everyone:F` | tamper block |
| Disable the vendor task | `schtasks /change /tn "Agent Blackbox dashboard" /disable` | tamper block |
| Clear the audit policy | `auditpol /clear /y` | block |
| Delete shadow copies | `wmic shadowcopy delete` | block |

`_disables_guard` pairs a stop/disable/overwrite verb (`sc stop|delete`, `Stop-Service`,
`Set-Service`, `net stop`, `taskkill`, `schtasks /change|/delete`, `Unregister-ScheduledTask`,
`icacls`, `del/erase/rm/rmdir`, `Remove-Item`) with an Axiom target (`axiom`, `axiom.service`,
`axiom\modules`, `\local\axiom`, `agent-evidence`, `agent blackbox`, `hermes\blackbox`).
`auditpol /clear`, `shadowcopy delete` and `wmic shadowcopy` block unconditionally.
