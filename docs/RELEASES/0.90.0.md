# Axiom 0.90.0

**Released:** 17 November 2026

## Right-click menus work again (issue #296)

Reproduced on the installed 0.89 build: right-clicking an Agent activity row selected it and filled
the details pane, but the popup that appeared was the **ScrollViewer's built-in scroll menu**
("Scroll Here / Top / Bottom / Page Up / Page Down"), not the row menu. The row's own
Copy event / Copy details / Copy raw event JSON menu never opened, so the clipboard stayed unchanged.

- The scroll menu is disabled with a `ScrollViewer` style (`ContextMenu = null`) so the row's
  attached context menu is the one that opens on every list page (activity, findings, connections,
  apps, events, firewall, privacy).
- Right-click already selects the row (`DataListSelection`), so the copy commands act on the row
  under the pointer.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed in the VM; right-click on an Agent activity row shows Copy event / Copy details /
  Copy raw event JSON and the copy command fills the clipboard.
