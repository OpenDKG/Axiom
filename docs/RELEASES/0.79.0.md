# Axiom 0.79.0

**Released:** 16 November 2026

## Blocked actions in the Simple view

0.77.0 put the blocked-action chart on the Advanced Agents dashboard. The Simple view still showed
only a guard status card and the live activity feed, and its blocked-tool-call wording was ambiguous
next to the audit's blocked-findings KPI.

- `SimpleHomeView` now has a compact **Blocked actions by agent** card (top five agents by blocked
  tool calls, with a **Details** button that opens the Agents dashboard). It binds the same
  `AgentBlockSummary` the Advanced chart uses, so the numbers cannot drift apart.
- `AgentBlockSummary` carries explicit `HarnessCount`/`ReasonCount` totals, so the subtitle now says
  "…across 11 agent(s)" instead of the number of bars on the chart.
- The Advanced KPI is labelled **BLOCKED FINDINGS** ("explicit block decisions in the audit") while
  the chart says "blocked tool calls of N guard decisions" — two different sources are no longer
  presented as the same number.
- `BlockedActionsChart` gained a `MaxRows` bound so compact views can show the top rows only.
