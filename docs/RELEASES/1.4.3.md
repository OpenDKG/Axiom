# Axiom 1.4.3

**Released:** 19 November 2026

- **Upgrade & Complete setup dashboard startup:** `OptionalModuleInstaller.InstallBlackboxAndWait` (both `Axiom.Presentation` and `Axiom.UI`) now verifies dashboard Python dependencies and starts the Blackbox dashboard on `127.0.0.1:9700` even when reusing a previously installed pinned build marker, and `SetupInstaller` explicitly invokes `StartBlackboxDashboard()` if port `9700` is not yet listening after runtime configuration.
- **`pythonw.exe` null-stream crash & hidden-subprocess fix:** Redirects `sys.stdout` and `sys.stderr` to `os.devnull` when `None` inside the generated `start-dashboard.py` launcher so launching `pythonw.exe` from the desktop GUI without console handles no longer fails on stream/TTY checks inside Uvicorn or dashboard startup, injects `CREATE_NO_WINDOW` / `STARTF_USESHOWWINDOW` (`SW_HIDE`) into Windows subprocess calls spawned by the dashboard during sync/status operations (plus upgrades/restarts an already-running outdated launcher automatically), and runs `EnsureBlackboxDependencies()` on dashboard launch (ignoring zero-byte test stubs).
- **PowerShell 5.1 vendor installer resilience:** Switches `$ErrorActionPreference` to `'Continue'` inside a `try/catch` block around `& $installer -StoreBackend $storeBackend` (and guards `& py -3.12 --version` in the WPF script) so vendor `stderr` output cannot abort Windows PowerShell 5.1 before dependency repair and dashboard startup run.
- **Agent Activity agent filter list:** Adds `Antigravity` to the agent selector dropdown in Agent Dashboard / Agent Activity (`AgentsPageViewModel` and WPF `AgentsViewModel`) and removes the duplicate `OpenChamber` selector option while keeping OpenChamber hooks intact and displaying `openchamber` events under `OpenCode`.
