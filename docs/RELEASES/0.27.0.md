# Axiom 0.27.0

**Released:** 14 November 2026

0.27.0 fixes table row selection and context-menu copy in the Agent Activity, Security Findings, and Hook Evidence views (#296) and removes all remaining UTF-8 / Windows-1252 / CP437 mojibake across the UI, scripts, and docs with an automated source-encoding guard (#299).

## Highlights

- **Reliable click, right-click & keyboard row selection (#296, `00008f1`).**
  - Table cells in `AgentDashboardView` and `AgentStatsView` now use `TextBlock` with transparent row `Grid` hit-testing, while the right-hand details panes retain `AxiomSelectableTextBlock` so details text remains selectable and copyable.
  - Added `DataListSelection.SelectOnPointerPress` (`Tunnel` `PointerPressed` + `ContextRequested`) and fixed `MainWindow.SelectContainingListItem` (walking visual ancestors past `ItemsPresenter`/`VirtualizingStackPanel` to the owning `ListBox`). Left-clicks, right-clicks, and context menus now reliably select the row under the pointer before opening.
  - Row `ContextMenu` items now forward `PlacementTarget.DataContext` via `CommandParameter`, and `AgentsPageViewModel` copy commands resolve the target row consistently across both context menus and details-pane buttons.
  - Periodic background refreshes preserve selection and details state across Activity, Findings (`_preservingFindingSelection`), and Hook Evidence (`ApplyHookEvidence`).
- **UTF-8 / cp1252 / CP437 mojibake cleanup & guard (#299, `e369fbc`).**
  - Repaired mojibake in `AgentHealthView.axaml`, `AgentsView.axaml`, `AgentDashboardView.axaml`, `BlackboxDashboardClient.cs`, `OpenCodeProtection.cs` (Presentation & UI), `README.md`, `docs/CHANGELOG.md`, and `docs/RELEASES/0.26.0.md`.
  - Added `SourceEncodingRegressionTests` to block future mojibake regressions in `src/`.
