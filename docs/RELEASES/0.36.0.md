# Axiom 0.36.0

**Released:** 15 November 2026

0.36.0 adds Axiom-owned prompt-injection heuristics for phrasings the vendor's curated regexes
missed in the lab: plain "ignore previous instructions", "before answering, run …" and zero-width
obfuscation. It also lands the 11-host template verification from the previous nightly run.

## Fixes

- **Injection phrase heuristics.** `_flatten_args` concatenates every string value and key of the
  tool arguments (the same scope the vendor scans) and `_axiom_injection` matches:
  - `ignore all previous instructions`, `ignore previous instructions`
  - `disregard previous/prior instructions`, `forget previous instructions`
  - `ignore the above instructions`
  - `before answering, run` / `before answering run`
  - `system override:`
  - zero-width and BOM characters are stripped before matching (`\u200b`, `\u200c`, `\u200d`,
    `\u2060`, `\ufeff`).
- The OpenCode bridge checks the payload before the vendor guard and returns a named
  `injection-heuristic` block; `_check_command_safety` applies the same check to the other host
  adapters.
- The check is phrase-based and only blocks when one of those exact phrases appears in the tool
  arguments; ordinary commands and file writes without them are unaffected.
