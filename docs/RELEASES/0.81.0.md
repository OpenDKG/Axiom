# Axiom 0.81.0

**Released:** 16 November 2026

## Status bar, footer links, update button and donations

- **Shield lamp** follows the real state: green with protection on, red when off, amber only for the
  test-VM writes state (it was hard-coded amber).
- **Axiom logo and version** in the navigation footer are now a button that opens
  `https://opendkg.org/axiom` (tooltip included).
- **Update button** moved to the right of the notifications bell; its tooltip reads
  "Update to version X". It still appears only when the GitHub release check finds a newer version.
- **Support page** keeps only GitHub Sponsors; the Buy Me a Coffee and PayPal.Me buttons are gone,
  and the navigation Donate entry still opens the same page.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed and inspected in the lab VM.
