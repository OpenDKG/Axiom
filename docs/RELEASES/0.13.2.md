# Axiom 0.13.2 — Bugfix & Reliability Release (#267–#273)

**Release date:** 2026-11-12  
**Version:** `0.13.2`  
**License:** GPL-3.0-or-later

## Resolved Issues

- **#270 — Fixed AI Analyst settings clearing the active API key after Save (`AiAnalystPageViewModel`):**
  - Resetting `ApiKeyInput = string.Empty` after saving settings now suppresses `OnApiKeyInputChanged` so the active `_apiKey` remains intact in memory and `_apiKeyDirty` stays `false`.
- **#268 — Fixed unchanged active connections vanishing from recent history (`HistoryStore`):**
  - `HistoryStore.UpsertAsync` now tracks `(Fingerprint, CapturedUtc)` per flow and updates `last_seen_utc` on each new snapshot capture timestamp instead of waiting 6 hours, ensuring long-lived active connections stay visible in `15m` / `1h` history queries.
- **#269 — Fixed `Network Events` dropping filter changes during in-flight queries (`EventsPageViewModel`):**
  - Filter/range/search changes while `IsLoading` is true now queue an immediate follow-up query and prevent stale responses from being rendered under the newer filter label.
- **#271 — Fixed `AgentEvidenceStore` tail reader truncating history for >512-byte records (`AgentEvidenceStore`):**
  - `ReadTailEvents` dynamically doubles its tail window until the requested number of valid JSONL records is collected or the start of the file is reached.
- **#272 — Fixed unhandled child-process error when OpenCode lifecycle bridge executable is missing (`OpenCodeProtection`):**
  - Registered `child.on("error", ...)` and `child.stdin.on("error", ...)` in `runLifecycleBridge` across both `Axiom.Presentation` and `Axiom.UI`.
- **#267 — Fixed SPDX header comment in `scripts/publish-setup.ps1`:**
  - Replaced `<# SPDX-License-Identifier: GPL-3.0-or-later` on line 1 with a standard `#` line comment.
- **#273 — Added automatic Build & Test GitHub Actions workflow (`.github/workflows/ci.yml`):**
  - Runs PowerShell AST parse validation across `scripts/*.ps1`, `dotnet restore --locked-mode`, `dotnet build -c Release`, and `dotnet test -c Release` automatically on pushes and pull requests.
