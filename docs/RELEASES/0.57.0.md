# Axiom 0.57.0

**Released:** 15 November 2026

0.57.0 redesigns `Axiom Glass Dark` and `Axiom Glass Light` for a continuous frosted glass canvas and
harmonizes all four non-transparent themes (`Dark`, `Light`, `Dark Midnight`, `Light Warm`) around the
same geometry and the monochrome `0.56.0` **AXIOM** brand palette.

## What changed

- **Open frosted Glass architecture (`MainWindow.axaml`, `AxiomControls.axaml`, `AxiomPalette.axaml`):**
  - Removed solid chrome divider walls (`Border.glass-chrome` borderless across titlebar, navigation rail, header, and status bar), unified controls and cards to `CornerRadius="6"`, and removed heavy boxy drop shadows from glass cards.
  - Set `TransparencyBackgroundFallback="Transparent"` on `MainWindow` so `Glass Dark` keeps true desktop backdrop translucency without a black fallback flash, while `UpdateBackdropTint` applies a dimensional gradient fallback when native backdrop is `None`.
  - Rebuilt `Glass Dark` with a deeper smoked slate-obsidian veil (`#780C111A` -> `#66131B28` -> `#7D0A0F17`), frosted white-smoke tiles (`#1FFFFFFF` -> `#10FFFFFF`), and crisp white/silver contrast.
  - Rebuilt `Glass Light` with a frosted crystal veil (`#8AF4F7FB` -> `#7AEAF0F7` -> `#85E2EAF3`) and `#2B313A` gunmetal graphite accents.
- **Harmonized non-transparent themes (`Dark`, `Light`, `Dark Midnight`, `Light Warm`):**
  - Updated all four opaque themes to share the seamless divider-free layout, subtle hairline fade card borders, and dimensional opaque gradient window bases with no desktop transparency:
    - `Dark`: smoked slate matching `Glass Dark` with `#E2E8F0` chrome accents.
    - `Light`: crisp silver-quartz matching `Glass Light` with `#2B313A` graphite accents.
    - `Dark Midnight`: deep midnight indigo with `#A5B4FC` periwinkle-platinum accents.
    - `Light Warm`: warm alabaster/titanium neutral with `#443C35` obsidian-bronze accents.
