# Axiom 1.4.1

- Axiom's support screen offers an optional ETH donation on Ethereum mainnet with an Ethereum logo and a copyable recipient address.
- The repository links to the shared [Axiom and OpenDKG donation page](https://opendkg.org/donate/).

## Downloads

- Windows x64: `Axiom-Setup.exe` and `Axiom-1.4.1-win-x64.zip`.
- macOS Intel developer preview: the ad hoc-signed application archive. The system extension has separate signing and activation requirements.
- Linux amd64 core preview: the Debian package.

The release identifies the version of each native preview. Use the SHA-256 manifest to verify the downloads.
