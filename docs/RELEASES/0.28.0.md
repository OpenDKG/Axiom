# Axiom 0.28.0

**Released:** 14 November 2026

0.28.0 resolves host-mask firewall rule readback verification (#282), enforces single-instance desktop startup before Avalonia Dispatcher initialization (#283), adds the dedicated `Phishing` category across contracts/service/UI, fixes 8-source Privacy Shield toggling and timeouts, and makes automatic adapter DNS pointing reliable in Complete Setup and the background service.

## Highlights

- **Firewall bare-host readback normalization (#282, `303b6ee`).**
  - Normalized `/32` IPv4 and `/128` IPv6 CIDR suffixes during firewall rule readback/verification so bare IPv4/IPv6 host scopes verify and apply cleanly.
- **Clean single-instance enforcement on desktop launch (#283, `8772b23`).**
  - Moved single-instance mutex checking in `Axiom.Desktop.Avalonia.Windows` before `BuildAvaloniaApp().StartWithClassicDesktopLifetime` so second-instance launches show a clean message instead of crashing in the Avalonia dispatcher.
- **Dedicated `Phishing` category and UI checkboxes (`7ab4045`).**
  - Added `PrivacyCategory.Phishing` (`64`) to contracts/service/UI, included it in `PrivacyShieldProfile.Strict`, tagged `phishing-filter` (`Phishing`) and `hagezi-tif` (`Malware | Phishing`), prioritized `Malware | Phishing` feeds during updates, and exposed the `Phishing` checkbox in both Avalonia and WPF Privacy Shield pages.
- **Large blocklist normalization performance (`9451c56`).**
  - Replaced per-domain `IdnMapping` allocations and splits in `PrivacyShieldPolicy.NormalizeDomain` with `[ThreadStatic] IdnMapping` and zero-allocation ASCII validation for 700k+ rule rebuilds.
- **Reliable 8-source blocklist toggles & IPC timeouts (`af60196`).**
  - Increased `PrivacyConfigure` (`60s`) and `PrivacySourcesUpdate` (`5m`) IPC client timeouts across Avalonia, WPF, and `PrivacyShieldProvisioner`, bound source checkboxes `Mode=TwoWay`, added stale-service source-drop diagnostics in `PrivacyShieldPageViewModel`, and signaled `PrivacyShieldWorker` for immediate source sync after `Apply`.
- **Reliable automatic adapter DNS pointing in Setup & service (`f5420ab`).**
  - Improved `PrivacyDnsFailSafe.BuildFallbackCandidates` and `SelectTargetAdapter` (loopback/site-local filtering, saved -> current -> gateway/DHCP IPv4 fallback, physical-before-virtual adapter sorting, 45s timeout with safe process kill), added a 30s reconciliation loop in `PrivacyShieldWorker`, registered `Axiom.Service.exe` up front during Complete Setup (preserving a single UAC prompt), updated `SetupWindow.xaml`, and stopped overwriting user-edited `privacy-shield.json` on startup.
