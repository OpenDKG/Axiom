# Axiom 1.4.2

**Released:** 19 November 2026

- **Native handle & memory leak fixes:** Fixes WinTrust (`WTD_STATEACTION_CLOSE`) state-handle and `WinTrustFileInfo` string destruction in `ProcessMetadataProvider.VerifyAuthenticode`; wraps `TcpConnectionByteReader`'s native buffer in `SafeHandleZeroOrMinusOneIsInvalid` with `IDisposable` propagation to `IpHelperConnectionSource` and `MonitoringWorker`; disposes `Process`, `SqliteCommand`, and `ManagementBaseObject` handles cleanly across monitoring, installer, uninstaller, and module-window cleanup paths; and detaches Avalonia visual/event subscriptions across `TrafficChartControl` and code-behind views on detach/dispose.
- **IPC, DNS & service concurrency fixes:** Advertises enforcement IPC capabilities in `PipeServer`, resets the per-request idle timeout per frame, validates `QR == 1` and `QDCOUNT == 1` DNS response packets and adds a 10 s `DnsProxyServer` TCP timeout, serializes `ProtectionController` state transitions and `PrivacyShieldController` status mutations, fixes `HistoryWriter` shutdown flush reachability on cancellation, enables SQLite `busy_timeout=5000` in `HistoryStore`, and prunes overflow entries in `ThreatShareController._knownIds`.
- **Subprocess, PowerShell 5.1 & Setup reliability:** Isolates PowerShell 5.1 `$ErrorActionPreference` around native `stderr`-producing tools (`$dkg stop`, Python version probe, `git -c core.autocrlf=false checkout -- .`), eliminates synchronous `ReadToEnd()` deadlocks and unobserved task exceptions on canceled subprocesses, enforces root-path containment in `UpgradeDataGuard`, fixes Setup service detection (`sc.exe query Axiom`) with retry deletion for locked binaries and `--install-dir=` parsing, and adds lifecycle/security/leak regression tests across all affected suites.
