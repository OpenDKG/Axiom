# Axiom 0.71.0

**Released:** 16 November 2026

## Guard

Batch 11 probed cloud/IaC and chat-app secret stores on 0.70 hooks (issue #397).

Blocked already: `~/.npmrc`. Controls (`~/.gitconfig`, project README) allow.

Found and fixed:

| Probe | Path | Now |
| --- | --- | --- |
| Terraform state | `terraform.tfstate` | credential-store block |
| Terraform CLI token | `~/.terraformrc` | credential-store block |
| Pulumi credentials | `~/.pulumi/credentials.json` | credential-store block |
| GitHub CLI token | `~/.config/gh/hosts.yml` | credential-store block |
| Slack tokens | `%APPDATA%\Slack\tokens.json` | credential-store block |
| Discord storage | `%APPDATA%\discord\Local Storage\leveldb\…` | credential-store block |
| VS Code global state | `%APPDATA%\Code\User\globalStorage\state.vscdb` | credential-store block |

The Windows-only `github cli\hosts.yml` marker missed the `.config/gh` spelling; the other stores were
not named at all. `_sensitive_store` now covers all seven. Batch re-verified **10/10**; batches 1-10
stay clean and `AgentCommandGuardTests` gains a ninth test.

## Trade-off

`terraform.tfstate` and VS Code `state.vscdb` are read by legitimate tooling, but they routinely hold
plaintext credentials, so an agent read blocks by default — the same policy as `.env` and key files.
