# Axiom 0.19.0

**Released:** 14 November 2026

0.19.0 implements the Stage E1-to-E2 Host Enforcement Bridge (#322), hash-chained `EnforcementReceiptV1` audit receipts, strict `CommunityOnly` advisory gating, and honest UI distinction between guard detection and verified host refusal.

## Highlights

- **Verifiable receipt chain & `CommunityOnly` gate (#322, `6fcbb32`).** `EnforcementReceiptV1` separates `DETECTED`, `GUARD_UNAVAILABLE`, `AUDIT_ONLY`, `DENY_REQUESTED`, `HOST_DENY_SENT`, `HOST_DENY_VERIFIED`, `OS_DENY_VERIFIED`, `UNVERIFIED`, and `FAILED_OPEN`, while `EnforcementPolicyEvaluator` ensures unconfirmed community sightings never auto-block.
- **Host enforcement adapter & disposable canary verifier (#322, `5c9b76f`).** Added `HostEnforcementAdapter`, canary verification primitives, and strongly typed IPC contracts.
- **Service-side controller & E2B bridge spec (#322, `b7fa8b2`).** Wired `EnforcementController` and `PipeServer` enforcement endpoints alongside `docs/ENFORCEMENT_E2B_BRIDGE.md`.
- **Honest UI enforcement state & Blackbox hook evidence (#322, `c39f27c`).** Desktop pages display verified vs unverified enforcement provenance without claiming OS blocking before host confirmation.
