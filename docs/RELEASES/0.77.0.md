# Axiom 0.77.0

**Released:** 16 November 2026

## Blocked actions, visible at last

The Blackbox dashboard graph aggregates by *unique* threat rule, so a lab run with 3,189 blocked tool
calls still drew three local nodes. The numbers were correct, the picture was not.

The Agents dashboard now draws Axiom's own block counts from `agent-evidence.jsonl`:

- New `AgentBlockSummaryBuilder` aggregates `GUARD_BLOCKED` decisions per harness and per reason
  (escalation, protected read, guard tamper, credential store, exfiltration, permissions, prompt
  injection, protected delete, protected launch, other) plus totals for allowed and failed events.
- New `BlockedActionsChart` control renders the per-agent bars natively in the Avalonia app; the
  Agent activity card now shows "N blocked of M guard decisions across N agents" above it.
- Verified on the lab VM's evidence store: **3,189 blocked of 4,044 events**, claude 844,
  opencode 335, copilot 238, codex 237, cursor 225, antigravity 225, gemini 223, zcode 223,
  deepseek 223, cline 208, windsurf 208.

## Notes

- The vendor dashboard graph still shows aggregated verified-threat nodes; this view is the honest
  count of what the guard actually blocked, sourced from Axiom's evidence file.
- The lab's pinned DKG node remains unhealthy (vendor store errors) and shows `NODE OFFLINE`; the
  compiled ruleset (1,109,000 verified rules) keeps enforcing and the new chart is independent of it.
