# Axiom 0.63.0

**Released:** 16 November 2026

Stability release from the overnight lab run.

## What changed

- `DnsProxyTests.Proxy_blocks_matching_domains_over_tcp` no longer flakes on a busy CI runner
  (issue #374). The DNS proxy falls back to UDP-only when its TCP listener loses the bind race; the
  test now creates the proxy with up to five bind attempts (50 ms apart) before asserting the blocked
  response, so it measures block behaviour instead of timing. It failed once in 4 ms on the 0.58.0
  PR run and passed unchanged on rerun.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- `Axiom.Infrastructure.Windows.Tests` DnsProxyTests 11/11; full suite green before packaging.
- After publishing, the same release is installed in the lab VM silently and the harness sweeps are
  re-run on its hooks.

## Lab notes from the same run

- Guard: all ten harness hooks score 15/15, and a 24-probe gap sweep is clean after 0.61.0.
- Blackbox records (`agent-evidence.jsonl`, `hermes\blackbox\audit.jsonl`, dashboard 200) and the
  Hermes plugin loads after the 0.61.0 dependency repair.
- Axiom's firewall was verified end to end: `rule.apply` for `curl.exe` created
  `Axiom::<id>::OUT`, curl failed with exit 7 / HTTP 000, `rule.remove` deleted the rule and the
  same request returned 200. No owned rules exist by default, which is why the baseline count is 0.
