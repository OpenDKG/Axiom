# Axiom 0.56.0

**Released:** 15 November 2026

0.56.0 ships the intended lockup. The 0.55.0 brand release used an older `logo-letters.png`; this
release replaces it with the grayscale shield + AXIOM wordmark the artwork was meant to be.

## What changed

| Asset | Result |
| --- | --- |
| `src/Axiom.UI/Resources/axiom-lockup.png` | 2172×724, transparent, new grayscale lockup |
| `src/Axiom.UI.Avalonia/Assets/axiom-lockup.png` | 2172×724, transparent, same file |
| `packaging/msix/Assets/Wide310x150Logo.png` | regenerated from the new lockup |
| `packaging/msix/Assets/SplashScreen.png` | regenerated from the new lockup |

- The new lockup is 2172×724, exactly the historical canvas, so nothing changes in layout: the
  navigation rail (`Height=56`, `Stretch=Uniform`), the WPF header (176×59) and the first-run window
  (180×60) render it at the previous size with no stretching and no aspect change.
- The square tiles and `axiom-icon.png` / `axiom.ico` keep the mark from `logo.png`, which was already
  the correct one in 0.55.0.

## Verification

- `dotnet build Axiom.sln` — 0 warnings, 0 errors.
- Full test suite green before the release build.
- Rendered the new lockup at the navigation size (176×59 box) and the MSIX wide tile on the vendor
  dark background before publishing.
