# Axiom 0.85.0

**Released:** 16 November 2026

## Mini mode is a one-row overview again

The 0.83 Mini was a tall "blocked activity" feed: waiting-permission list plus three blocked lists. It
was not the compact overview the owner asked for, so Mini now shows one row of three statistic cards:

- **Agent dashboard** — sessions, tool calls, blocked (`BlockSummary`), flagged.
- **Network overview** — active sockets, processes, loopback, download and upload rates.
- **Privacy overview** — active rules, queries, allowed, blocked, errors.

Each card has an **Open** button that keeps the existing navigation. Below the row a small
**system throughput** chart plots the same upload/download series as the Network dashboard.

The Mini window now opens at 1040×660 (minimum 900×560) so the three columns and the chart fit; the
blocked lists and the waiting-permission queue remain on the full pages.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed on the host and in the lab VM; Mini screenshotted from the installed build.
