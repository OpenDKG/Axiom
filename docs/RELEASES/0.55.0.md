# Axiom 0.55.0

**Released:** 15 November 2026

0.55.0 replaces the Axiom brand mark throughout the product with the new logo art.

## What changed

| Asset | Source | Result |
| --- | --- | --- |
| `src/Axiom.UI/Resources/axiom-icon.png` | `logo.png` | 1024×1024 |
| `src/Axiom.UI.Avalonia/Assets/axiom-icon.png` | `logo.png` | 1024×1024 |
| `src/Axiom.UI/Resources/axiom-lockup.png` | `logo-letters.png` | 2172×1222 |
| `src/Axiom.UI.Avalonia/Assets/axiom-lockup.png` | `logo-letters.png` | 2172×1222 |
| `src/Axiom.UI/Resources/axiom.ico` | `logo.png` | 16, 20, 24, 32, 40, 48, 64, 128, 256 px |
| `packaging/msix/Assets/*` | `logo.png` + `logo-letters.png` | Store, Square 44/71/150/310, Wide 310×150, Splash 620×300 |

- Every replacement keeps the original transparent alpha; no background was baked in.
- The old lockup was 3:1, the new art is 1.78:1. The asset keeps its true aspect ratio, so the
  navigation rail (`Height=56`, `Stretch=Uniform`), the WPF header (176×59) and the first-run window
  (180×60) render it narrower instead of stretching it.
- `axiom.ico` drives the window icon, the tray icon and the installer icon
  (`Axiom.Setup` `ApplicationIcon`), so all three pick up the new mark.
- MSIX tiles and the splash were regenerated with the repository's own
  `packaging/msix/generate-assets.ps1`, which fits the new art onto the vendor's dark background.

## Verification

- `dotnet build Axiom.sln` — 0 warnings, 0 errors.
- Full test suite green before the release build.
- Rendered previews of the icon at 180/64/40/22 px, the lockup at the navigation size, the `.ico`
  frames and the MSIX wide tile were checked on dark and light backgrounds.

## Notes

- The standalone mark (`logo.png`) is grayscale while the lockup is blue and white; that matches the
  supplied art. Swapping the icon for a blue variant later only touches `axiom-icon.png` and
  `axiom.ico`.
