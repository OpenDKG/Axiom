# Axiom 0.84.0

**Released:** 16 November 2026

## Mini mode now shows the same block count as the dashboard

The Mini home's **AGENTS BLOCKED** card used `max(BlockedFindingCount, BlockedAgents.Count)`, i.e. the
audit's blocked *findings* (63 on the lab VM), while the Advanced chart counted `GUARD_BLOCKED` tool
calls (3,178). Two screens, two different numbers.

- `MiniHomePageViewModel.AgentsBlockedCountText` now reads `Agents.BlockSummary.Blocked` (guard
  evidence), falling back to the audit count only when the evidence store is empty.
- The card therefore shows "3,178 blocked" next to the blocked-agents list, matching the Agent
  Dashboard chart and the 0.79 Simple card.

## Notes

- The DKG workaround from the lab is not part of the product: a fresh install still rewrites
  `start-blackbox-dkg.ps1` with the default Node path, so the vendor node can crash-loop again. A
  vendor build update is required for a permanent fix (#315).

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed on the host and in the lab VM; Mini card checked on the installed build.
