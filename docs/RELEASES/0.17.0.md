# Axiom 0.17.0

**Released:** 12 November 2026

0.17.0 completes the Agent Health page with the Blackbox and module health surfaces. It also carries
everything prepared for 0.16.0, which was not published separately: the Agent Health page, the
Network Dashboard rename and four correctness fixes.

## Highlights

- **Agent Health is the full health surface.** In order: **Protected workspaces**, **Blackbox health**
  (Blackbox, DKG, Axiom DKG, verified graph, protection test, View DKG log) and **Module health**
  (DKG/Blackbox loopback samples). They moved out of Agent Protection, not duplicated. The page
  shares `AgentsPageViewModel` and `SecurityPageViewModel`, so the probes, samples and timers stay
  single-owner, and it activates the agents page so health keeps refreshing while it is selected.
- **Agent Health page (0.16.0).** A dedicated page directly below Agent Activity.
- **Network Dashboard (0.16.0).** The former Network page is now Network Dashboard, matching
  Agent Dashboard.
- **Network Events write gating (0.16.0, #288).** Block outbound/Block inbound, including context
  menu entries, are disabled when the service cannot apply firewall changes. The reason is shown
  next to them and the result of the last action stays visible across the 10-second refresh.
- **Accurate empty state (0.16.0, #287).** A search with no matches no longer claims the service is
  not running.
- **Read-only `rule.verify` (0.16.0, #277).** The service advertises `rule.verify` even when
  firewall writes are disabled; only `rule.apply` and `rule.remove` require the write capability.
- **Version-derived milestone (0.16.0, #278).** The FND-005 label reads the product version, so the
  service and both Settings pages show the same value.

## Upgrade notes

Install over 0.16.0 as usual; settings, the local database and agent hooks are preserved. If a
silent setup reports a non-zero exit code, the desktop is updated but the service helper may have
been skipped; run `%LOCALAPPDATA%\Programs\Axiom\Axiom.Service.exe --install-service` once elevated
to complete the service update.
