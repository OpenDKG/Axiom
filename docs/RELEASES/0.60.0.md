# Axiom 0.60.0

**Released:** 16 November 2026

0.60.0 redesigns the `Axiom Setup` wizard to match Axiom's desktop theme architecture and automates post-install and post-update startup and installer exit.

## What changed

- **Theme-synchronized modern `Axiom Setup` wizard (`SetupNativeWindow`, `SetupGdiPlus`, `SetupThemePalette`):**
  - Replaced legacy Win32 controls with a double-buffered GDI+ native setup window embedding `Axiom.Setup.Logo.png` (`Square150x150Logo.png`), DWM titlebar styling, unified `CornerRadius="6"` geometry, custom vector radio cards/checkboxes/progress bar, and dynamic palette loading via `ThemeSettingsStore.Load()` across all six Axiom themes (`GlassDark` smoked obsidian + `#E2E8F0` silver chrome by default, plus `Dark`, `DarkMidnight`, `GlassLight`, `Light`, and `LightWarm`).
  - Replaced the stacked radio/path wall on the initial screen with clean side-by-side **Complete Protection (`RECOMMENDED`)** and **Core / Partial Build (`NO ADMIN`)** mode cards, a dedicated **Write scope** view, an interactive **Development build notice** acceptance card, and a **Progress** view with elapsed timer, live step caption, animated progress sweep, and dark/themed scrollable log.
- **Automatic launch and self-closing behavior on Install & Update (`SetupInstaller`, `SetupNativeWindow`):**
  - `SetupInstaller.InstallAsync` now launches `Axiom.Desktop.exe` whenever `StartAfterInstall` is enabled (`true` by default) and the core application was installed or updated cleanly (persisting any optional-module warnings to `%LOCALAPPDATA%\Axiom\logs\setup-last-warning.txt`).
  - Interactive Install and Update (`Upgrade`) flows close the installer window automatically on completion with no blocking confirmation popup, and prompt to close any already-running `Axiom.Desktop` instance before updating in place.
