# Axiom 0.92.0

**Released:** 17 November 2026

## Windows CI is green again

The `main` push workflow had been failing since 0.89.0 in
`SimpleAndAdvancedModeTests.Titlebar_switch_toggles_between_simple_and_advanced_modes_and_renders_cleanly`.
The test added one blocked agent entry and then asserted it was the *only* entry in the Simple and
Mini agent lists. The self-hosted runner keeps a real local audit store, so runs that followed
another test or an install injected extra entries and the single-item assertion failed. Pull-request
runs passed because they happened to start from a cleaner store.

- The test now asserts that the entry it added is present (agent `Codex`) instead of assuming an
  empty audit store, which is what it actually needs to prove: the blocked agent reaches both the
  Simple and Mini views.
- No product behavior changes in this release.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- The fixed test and the full UI test project pass on the Windows runner; the `main` push workflow
  after this merge is green.
