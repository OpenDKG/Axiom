# Axiom 1.0.0

**Released:** 17 November 2026

> **Version line:** this is the first 1.x release. From here fixes and feature sets ship as
> `1.1.0`, `1.2.0`, and so on; patch releases are still not used.

## Privacy Dashboard

The page called **Privacy Overview** is now **Privacy Dashboard** everywhere: sidebar, page header
and the Mini mode card.

## Enforcement is colour-coded and warns when it is not protecting

The Agent Protection enforcement panel now reflects the real level:

- **Green** — protected: guard hooks are blocking (or a host/OS deny was verified).
- **Orange** — degraded: the guard is reachable but no block channel is proven (for example audit
  mode, or only a host-deny request without verification).
- **Red** — not protected: the guard is unavailable or the policy failed validation.

A one-time notification per level change says what happened and links to Agent Protection when the
level is degraded or unprotected. The panel text still states exactly what is and is not proven.

## Trader Shield moved to Integrations

The Trader Shield section was on Agent Protection; it now lives on the **Integrations** page with
the other optional modules. Its settings, self-test and wallet list are unchanged.

## Mini mode fits and shows module health

- A compact **Module Health** strip shows Guard, Blackbox and DKG at a glance with the same colours
  as the full pages.
- The throughput chart now takes the remaining height (minimum 48 px) instead of a fixed 96 px, so
  the Mini layout stays inside its fields and compacts further when the window is made smaller.

## Threat sharing is on with a Complete installation

The Complete installation consent now includes signed, redacted threat sharing:

- The setup records the consent in `install-profile.json` (`threatSharingConsent`).
- On first run Axiom applies it once through the Blackbox dashboard, explains what is shared in a
  notification, and never re-enables after the user turns it off.
- Only evidence-bound, signed and redacted indicators are sent. Prompts, commands, file paths,
  credentials, model content and session ids are never sent. The point is stated plainly in the
  app and the installer: sharing strengthens the verified graph for every install — *help me help
  you*.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- New tests: `ThreatSharingConsentTests` (consent parsing, missing/partial consent, applied marker).
- The existing policy/import/export tests still pass.
- Windows CI build, tests and packaging check pass; 1.0.0 installed on host and in the VM.
