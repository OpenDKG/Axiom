# Axiom 0.41.0

**Released:** 15 November 2026

0.41.0 implements F-19 part C at the planning layer: an Axiom-owned per-process egress block for
one executable, for the case where an agent-spawned binary should not reach the network at all
(this covers IP-based C2 the DNS shield cannot see).

## What this adds

- `AgentFirewallRulePlanner.BuildProcessEgressBlockSpec(executablePath, actorSid, origin,
  explicitlyAuthorizedByUser)`:
  - requires explicit user authorization (community/public signals are advisory only);
  - requires an absolute executable path and a caller SID;
  - refuses Windows system binaries, so the rule cannot cut off the OS;
  - produces an outbound `Block` rule for the app with `RemoteAddresses = []` (any destination),
    `Protocol = Any`, all profiles, Axiom-owned rule id.
- Existing `RuleSpecValidator` and `RuleIdentity` are reused; no new firewall write path.

## Verification
