# Axiom 0.20.0

**Released:** 14 November 2026

0.20.0 delivers OS-native scoped network firewall enforcement for agent processes (Stage E4, #323), the Stage E3 Trusted File Broker prototype (#323), read-only offline DKG threat context annotations (#231), and the Umanitek upstream collaboration RFC (#324).

## Highlights

- **Stage E4 scoped agent firewall enforcer & dual-destination canary (#323, `63df6f7`).** Scoped Windows Firewall enforcement (`ScopedAgentFirewallEnforcer`), rollback guarantees, and dual-destination canary verification (`AgentFirewallCanary`).
- **Stage E3 Trusted File Broker & ADR 0012 (#323, `110ba72`).** Prototype capability broker (`TrustedFileBroker`), Windows runner probe, and architectural decision record `docs/ADR/0012-trusted-file-broker.md`.
- **Offline DKG context annotator & roadmap alignment (#231, #324, `16229f4`).** `DkgContextAnnotator` serves O(1) cached `Verified` / `Community` / `LocalFalsePositive` / `Unknown` badges without auto-blocking (`EnforcesBlock => false`), paired with `docs/UMANITEK_UPSTREAM_COLLABORATION_RFC.md` and `docs/ENFORCEMENT_TRACKER.md`.

## Verification
