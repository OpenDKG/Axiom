# Axiom 0.37.0

**Released:** 15 November 2026

0.37.0 extends the Axiom credential-store list to browser autofill/encryption material, Firefox
key databases and password managers, plus CLI/cloud token files that the first pass missed.

## Fixes

`_sensitive_store` (shared `AgentCommandGuard`) now also blocks:

- `.netrc`, `.pgpass`, `.vault-token`, `.config\gcloud`, `.azure`, `.password-store`
- Firefox `key4.db` and `logins.json`
- browser `Web Data` (autofill) and `User Data\Local State` (encryption key)
- 1Password store, Bitwarden and KeePass databases

The OpenCode bridge checks command text and the `path`/`filePath` argument; `_check_command_safety`
does the same for the other host adapters. Slash normalization is preserved, so `%APPDATA%/…` and
`$HOME/...` variants match.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- `dotnet test Axiom.sln -c Release --no-build -m:1` — full suite in the release run.
- Template test asserts every new store marker is present before the vendor guard.
- **Live VM verification is pending install** — the lab VM stays on 0.30.0.

Install over 0.36.0. No data migration.
