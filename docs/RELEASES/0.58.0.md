# Axiom 0.58.0

**Released:** 15 November 2026

0.58.0 refreshes the documentation screenshots so they match the 0.57 theme redesign and the 0.56
brand mark.

## What changed

Every image below was captured from the released **0.57.0** build on Windows 11, maximized at
1936×1056 (the opaque themes) with the real guard data from the lab:

| File | Content |
| --- | --- |
| `docs/assets/screenshots/axiom-glass-dark-full.png` | Axiom Glass Dark dashboard |
| `docs/assets/screenshots/axiom-glass-light-full.png` | Axiom Glass Light dashboard |
| `docs/assets/screenshots/glass-dark-native.png` | Glass Dark, native window |
| `docs/assets/screenshots/glass-light-native.png` | Glass Light, native window |

- The screenshots now show the 0.56 monochrome lockup in the navigation rail and title bar, the
  borderless frosted chrome from 0.57, and the current sidebar (`Agent Dashboard`, `Network
  Dashboard`, `Privacy Overview`, Settings, Help & Support).
- The Agent activity tables contain real lab activity (tool calls, blocked reads of protected paths,
  threat findings), so the dashboard no longer looks empty.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Full test suite green before the release build.
- Each file was opened and inspected after capture (layout, theme, legibility); no desktop
  wallpaper bleed-through is visible on the opaque themes, and the glass captures keep the true
  translucent backdrop.
