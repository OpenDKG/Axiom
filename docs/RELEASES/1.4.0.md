# Axiom 1.4.0 for Windows

This release combines the desktop updates prepared for 1.3.1 with connection monitoring fixes and clearer controls for sharing threat indicators.

## Agent Protection

- Complete Protection setup includes permission for manual reports in its existing agreement. Before sending, review the exact indicator, severity and context and confirm the Blackbox Reporter Terms.
- AI suggestions and DNS matches stay local. Community reports require reproducible evidence or curator confirmation. Private IP addresses, local domains, prompts, file paths and logs are excluded from Axiom reports.
- Agent Protection displays the status of Blackbox automatic sharing. Axiom's manual reporter requires that option to be off, records each attempt locally and leaves reports out of Blackbox's automatic retry and renewal queues.

## Desktop and reliability

- Live charts and full page refreshes pause when the window is hidden or minimized. Connection monitoring and agent block alerts continue in the tray. Background integration health checks run every 60 seconds.
- Connection sampling recovers after transient failures. Active pages refresh their summaries as new connection data arrives.
- Repeated DKG and Blackbox start requests share the same pending launch. Repair and cleanup operations have time limits.
- OriginTrail, Umanitek and Blackbox logos are larger and sit directly on the interface. A subtle shadow improves contrast in light themes.
