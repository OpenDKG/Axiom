# Axiom 0.26.0

**Released:** 14 November 2026

0.26.0 makes the agent guard bridge run under the interpreter that matches its dependency
environment. The OpenCode plugin starts the bridge with the vendor venv python; Hermes' package
manager commits a separate dependency environment and `activate_dependencies` swaps `sys.path` to
it, so a venv built for another Python minor imports compiled packages for the wrong ABI. Every call
logged `pydantic_core._pydantic_core` and `no tui_gateway`, and detectors could be skipped.

The bridge now re-execs the committed interpreter once, before it reads stdin, with
`AXIOM_BRIDGE_REEXEC` preventing a loop.

## Highlights

- **Bridge runs under the committed interpreter (`e880361`).** No per-call ABI warnings, the guard's
  full detector set loads, and decisions are unchanged (block remains block). The re-exec happens
  before stdin is consumed, so the plugin's payload is read once.
- Includes **0.25.0** (Trader Shield wallet/address UI, BIP-39 runtime normalizer, seed-phrase and
  keystore self-test) and **0.24.0** (default encrypted DoH on port 443).
