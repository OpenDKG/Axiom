# Axiom 1.4.7

- Complete installation (Windows Setup) and first-run setup (Linux, macOS, and Windows) now include explicit consent to enable Blackbox automatic community threat sharing by default upon installation; once applied (or toggled off), Axiom never overrides the operator's later choice.
- Blackbox automatic community sharing now uses a persistent two-way toggle on the Agents page and in the Blackbox Configure dialog across Windows, Linux, and macOS — turning automatic sharing off no longer hides the control, and turning it back on asks for explicit confirmation.
- Manual threat sharing now supports verifying and classifying queued AI Analyst indicators (`Verify…`) as well as queueing operator-verified IOCs directly (`Add indicator…`) via a new `threatshare.verify` IPC command and queue workflow, while keeping all local safety checks intact (rejecting public DNS resolvers, private/reserved IPs, shared hosting/CDN infrastructure, trackers, synthetic markers, and already-known/disputed/revoked entries).
- Cross-platform threat reporter resolution (`ThreatShareLauncher` and `ThreatShareCli`) now discovers POSIX Python interpreters (`bin/python` / `bin/python3`) and Hermes-installed Blackbox plugin trees on Linux and macOS in addition to Windows.
