# Axiom 0.83.0

**Released:** 16 November 2026

## Compact Mini Mode (`Mini | Simple | Advanced`)

- Added a **Mini** mode toggle alongside **Simple** and **Advanced** in the top titlebar (`UiMode.Mini`, persisted via `UiModeSettingsStore`).
- Switching to **Mini** hides the 252px sidebar, header, and bottom status bar and shrinks `MainWindow` to `460×700` (`MinWidth = 420`, `MinHeight = 520`), restoring the previous window dimensions when returning to **Simple** or **Advanced**.
- `MiniHomeView` (`MiniHomePageViewModel`) displays one-click **Shield: ON/OFF**, **Privacy: ON/OFF**, and **Expand** controls, pending outbound approvals, and dedicated blocked-only panels for **Network Blocked**, **Agents Blocked**, and **Privacy Blocked**, alongside a bottom bar with the Axiom logo/version, **♥ Donate**, **GitHub**, and **Settings**.
