# Axiom 1.4.4

- Fixed Windows console windows stealing focus during Blackbox verified-graph sync. Axiom now applies the dashboard's quiet subprocess settings to its separate Python sync worker and restarts the old dashboard and worker on upgrade.
- Included the Blackbox auto-start and Agent Activity improvements from 1.4.3.
- Removed the frames around OriginTrail, Blackbox and Umanitek in Agent Protection. The logos use transparent graphics, high-quality scaling and a shadow suited to the active Avalonia theme.
- Switched desktop update checks and GitHub links to the public OpenDKG/Axiom repository. The website logo links to the Axiom site and brightens on hover.

Windows is distributed as an x64 installer and portable ZIP. The Linux package targets Ubuntu 24.04 amd64. The macOS Intel preview uses an ad hoc-signed app bundle and has separate system extension activation requirements. Verify packages against the SHA-256 files on the release page.
