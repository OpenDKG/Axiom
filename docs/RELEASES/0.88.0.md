# Axiom 0.88.0

**Released:** 16 November 2026

## Footer and Mini sizing

- Mini opens at 820×640 so the footer (Axiom logo, Donate, GitHub, Settings) is visible without
  resizing; the cards still size to their content.
- The Axiom logo/version in the footer is a clickable link in **every** mode and opens
  `https://opendkg.org/axiom`, including Mini.
- Logo/version buttons are ghost links: no grey box in the normal state, only a soft theme-aware
  highlight on hover (light in dark themes, dark in light themes).

## Brand icons

- Updated `axiom-icon`, `axiom-lockup`, `blackbox-logo`, `origintrail-logo` and `umanitek-logo`
  included from the owner's asset drop.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed on the host and in the lab VM; Mini screenshotted from the installed build.
