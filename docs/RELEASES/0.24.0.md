# Release 0.24.0

Date: 2026-11-14

## Summary

- **Default ISP-blind encrypted RFC 8484 DNS-over-HTTPS (DoH over port `443`)**
  - Added `EncryptDnsViaDoh` (`true` default) to `PrivacyShieldSettings` (`Axiom.Contracts`) and `PrivacyShieldPolicy.DefaultDohUpstream` (`"1.1.1.1, 9.9.9.9"`).
  - Added multi-target `SystemDnsResolver.TryParseUpstreamTargets` (comma/semicolon-separated DoH/UDP/TCP resolvers with strict `FallbackToPlainAllowed = false` for DoH) and `SystemDnsResolver.DefaultDohTargets()` (Cloudflare + Quad9 DoH over TLS port `443`).
  - Updated `PrivacyShieldController.TryCreateServer` and `CreateStatus()` so empty/automatic `UpstreamDns` never silently forwards unencrypted UDP port `53` DNS queries to a LAN router or ISP resolver when `EncryptDnsViaDoh` is enabled; users who need an internal LAN/corporate resolver can disable `EncryptDnsViaDoh` or configure `udp://IP` explicitly.
  - Defaulted Complete setup (`SetupDefaults` and `PrivacyShieldProvisioner.CompleteProfileSettings`) to `UpstreamDns = "1.1.1.1, 9.9.9.9"` and `EncryptDnsViaDoh = true`, and exposed `Encrypt upstream DNS via DoH (port 443 — hides queries from your ISP)` in both Avalonia (`PrivacyShieldView.axaml`) and WPF (`PrivacyShieldView.xaml`).
