# Axiom 0.86.0

**Released:** 16 November 2026

## Mini layout back to the compact overview

The one-row overview is restored to the compact shape the owner had before: three statistic cards,
a full-width throughput chart with the current rates in its header, and a short agent-activity list
under it.

- **Network overview** shows Active sockets, Processes, Loopback and a single **Throughput** value.
- **System-wide throughput** is a card with `Down:`/`Up:` rates top-right and the chart below.
- **Agent activity** lists the four most recent guard-observed actions (time, agent, action,
  outcome) and opens the Agents dashboard.
- Mini opens at 1040×720 (minimum 900×600) so the chart and list fit.

## Glass Dark buttons

- Default glass buttons are now dark grey with white text instead of translucent white.
- The selected/dark-theme primary button is a slightly lighter grey with **green** text.
- Hover/pressed states keep the same contrast; the change is limited to the glass themes.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed on the host and in the lab VM; Mini screenshotted from the installed build.
