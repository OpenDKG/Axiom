# Axiom 0.82.0

**Released:** 16 November 2026

## Status bar, footer, update button, donations and enforcement wording

- **Shield lamp**: green with protection on, red when off, amber only for the test-VM writes state
  (it was hard-coded amber).
- **Axiom logo and version** in the navigation footer open `https://opendkg.org/axiom`.
- **Update button** moved right of the notifications bell; tooltip reads "Update to version X"; shown
  only when the GitHub release check finds a newer version.
- **Support** keeps only GitHub Sponsors; Buy Me a Coffee and PayPal.Me removed.
- **Agent Protection wording** now matches reality: with the policy enabled the page says
  "HOOK BLOCKING ACTIVE — guard hooks block protected reads, writes and credential stores; no host
  or OS deny receipt has been recorded yet." The managed runner/broker is described as the E3
  prototype it is, and the block-mode detail states kernel/WFP deny is not enabled.

## Tests

- `EnforcementSurfaceTests` checks the new broker wording.
- `UpdateIndicatorAndContactTests` checks the new tooltip text.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed in the lab VM and on the host after publishing.
