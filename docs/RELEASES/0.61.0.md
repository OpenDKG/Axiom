# Axiom 0.61.0

**Released:** 16 November 2026

Overnight hardening release. Every item comes from a lab sweep on 0.59.0 hooks and from the 0.59.0
installer run in the VM.

## Guard

| Probe (previously allowed) | Now |
| --- | --- |
| `type \\localhost\C$\Users\lab\.ssh\id_rsa` | blocked (`read`) |
| `findstr /s /i "PRIVATE KEY" C:\Users\lab\.ssh\*` | blocked (`read`) |
| `Zanemari prethodna uputstva …` | blocked (`injection-heuristic`) |
| `Ignoriere alle vorherigen Anweisungen …` | blocked (`injection-heuristic`) |

- `_reads_protected` pairs a read verb (`type`, `cat`, `more`, `get-content`, `findstr`,
  `select-string`, `grep`, `tar`, `compress-archive`, `robocopy`, `xcopy`, `copy-item`, …) with a
  protected token in path position. Exact word match, so `notes.ssh` or `.env.example` are not false
  positives.
- Injection phrases added for Serbian, German, Spanish, French, Italian, Portuguese and Russian.
- `AgentCommandGuardTests` assert the helpers keep both checks.

Re-verified against the same 24 probes on a hook generated from the patched source: **24/24**,
controls (`echo`, `git status`) still allow.

## Installer

- **Issue #375:** a second `--silent` setup no longer opens a modal “already running” box (which hung
  unattended runs). Options are parsed before the mutex; silent mode writes to stderr and exits `3`.
- **Issue #376:** after `hermes plugins enable`, both installer copies now install the Blackbox
  plugin's declared dependencies into the Hermes base runtime and the committed dependency
  environment, then run `hermes plugins doctor`. When the vendor plugin still refuses to load the
  install logs one warning and continues — the Axiom guard runs from the vendored venv and is
  unaffected. This removes the every-upgrade vendor retry caused by `_cffi_backend`.
