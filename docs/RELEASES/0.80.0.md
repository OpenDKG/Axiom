# Axiom 0.80.0

**Released:** 16 November 2026

## Sessions counter on the Agents dashboard

The **SESSIONS** card always read 0 on the Advanced dashboard. It counted audit rows in the
`sessions` category, and hosts that never emit `session_start`/`session_end` produce none — the VM's
audit had 0 such rows over 2,753 events even though 333 agent sessions were recorded.

- New `AgentActivityMetrics.CountSessions` counts **distinct non-empty session ids** across the
  audit rows; the card falls back to the old category count only when no ids exist.
- VM verification: 125 distinct session ids in the first 1,000 audit rows (the dashboard loads up to
  20,000), matching the local-activity session list instead of zero.
- Tests: `AgentActivityMetricsTests` covers repeated ids, blank ids and the empty store.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors; suite green before packaging.
- Installed in the lab VM and on the host; both views screenshotted from the installed build.
