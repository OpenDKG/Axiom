# Release 0.25.0

Date: 2026-11-14

## Summary

- **BIP-39 Seed-Phrase Runtime Repair & Trader Shield Guard Verification (`#320`, `#324`)**
  - Added `BlackboxWordlistNormalizer` to repair Windows CRLF line endings back to LF (`2f5eed53…`, `13,116` bytes) across all installed Blackbox wordlist locations (`Axiom\modules\blackbox\agent-blackbox`, `%LOCALAPPDATA%\hermes`, and `~/.hermes`) during install, startup provisioning, dashboard startup, and Trader Shield self-test.
  - Updated `OptionalModuleInstaller` (`Axiom.Presentation` and `Axiom.UI`) to normalize all three wordlist copies during install and dashboard launch.
  - Fixed `AgentProtectionSelfTest.Identifier` regex to extract underscore tool identifiers (`fileaccess:read_file:crypto-wallet`) and secret identifiers (`secret:seed-phrase`).
  - Fixed `AgentProtectionSelfTest.DefaultChecks()` protected-read check (`a57ebbe`) and `TraderShieldChecks()` keystore-read check to resolve `%USERPROFILE%\.ssh\id_rsa` and `%APPDATA%\Exodus\exodus.wallet\seed.seco` from the signed-in account rather than a hardcoded lab path.
  - Added `AgentProtectionSelfTest.TraderShieldChecks()` and `ProtectionProvisioner.RunTraderShieldSelfTest()` verifying a synthetic non-uniform labelled BIP-39 seed-phrase write (`secret:seed-phrase` -> `block`) and an Exodus wallet keystore read (`fileaccess:read_file:crypto-wallet` -> `block`) through the local `axiom-guard-bridge.py` (`venv\Scripts\python.exe`).
  - Extended `TraderShieldProvisioner` with `Read`, `ReadFromFile`, `ResolveConfigPath`, and per-wallet selection filtering across all 11 supported wallets.

- **Trader Shield UI Settings & Self-Test (`#320`)**
  - Added `TraderShieldSectionViewModel` and reusable `TraderShieldSectionView` (enable/disable toggle, checkboxes for all 11 supported wallets, validated local-only `0x...` EVM address list, Save button preserving all other Hermes YAML keys, and live Run self-test button).
  - Embedded `TraderShieldSectionView` on both the **Security (Integrations)** page (`SecurityView.axaml`) and the **Agents** page (`AgentsView.axaml`) backed by `SecurityPageViewModel.TraderShield`.
