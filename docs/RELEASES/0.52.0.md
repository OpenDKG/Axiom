# Axiom 0.52.0

**Released:** 15 November 2026

0.52.0 wires live enforcement status telemetry into **Agent Protection**, adds a dedicated **Privacy Overview** live DNS monitoring page under **OVERVIEW**, integrates **Privacy Shield** counters (`Active rules`, `Queries`, `Allowed`, `Blocked`, `Errors`) into **Network Dashboard**, and validates both the Avalonia and WPF UIs.

## What this adds

- **Live `Enforcement` status (`Agent Protection`):**
  - `EnforcementSurfaceState.FromReceiptsAndStatus(...)` now accepts live Blackbox hook mode (`block` / `audit`) and recent hook deny counts alongside service IPC telemetry (`enforcement.status` and `enforcement.receipts`).
  - `AgentsPageViewModel` updates `Enforcement` during `RefreshAsync()` instead of showing a static fallback, while preserving all ADR 0010 cooperative honesty invariants.
- **New `Privacy Overview` page (`OVERVIEW` navigation group):**
  - Reuses the single-owner `PrivacyShieldPageViewModel` (`PrivacyOverviewPageViewModel` / `PrivacyOverviewView.axaml`) for 2-second live resolver monitoring (`ACTIVE RULES`, `QUERIES`, `ALLOWED`, `BLOCKED`, `ERRORS`, block rate, DoH/adapter alerts, live blocked feed, top blocked domains, and per-app blocked history) with direct navigation to `Privacy Shield` configuration.
- **`Network Dashboard` DNS monitor integration (Avalonia + WPF):**
  - `OverviewPageViewModel` / `OverviewView.axaml` (Avalonia) and `OverviewViewModel` / `OverviewView.xaml` (WPF) now show an embedded **Privacy Shield (DNS Monitor)** summary card with resolver badge, active rules, queries, allowed, blocked, errors, and quick navigation.
