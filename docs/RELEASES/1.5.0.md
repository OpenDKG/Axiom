- **Cleaner uninstall & downgrade safety**: Uninstalling Axiom now removes Axiom-owned firewall rules, restores DNS settings, removes the Windows service and agent hooks, and lets you choose whether to keep or delete saved data. Setup also prevents accidental downgrades.
- **Stronger stability & process protection**: Prevents blocking critical system processes, verifies process identity before ending an app, logs unexpected crashes locally, and accurately reports Offline status when the local service is not running.
- **Smarter AI Agent Guard**: Improved shell command parsing eliminates false blocks on normal developer commands while keeping protection active against tampering and credential access.
- **Strict opt-in privacy & local data controls**: Automatic community threat sharing is now off by default, and a new Settings option lets you clear local logs and caches without affecting firewall rules.
- **Faster update alerts & lower tray usage**: Axiom checks for updates on startup and every 30 minutes with a desktop alert, and pauses 1-second connection polling while minimized to the system tray.
- **Community**: Added a Special Thanks section in Settings -> About Axiom, starting with @hottogo.
