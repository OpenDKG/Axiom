# Axiom 1.5.0

- **Clean uninstall & downgrade protection (#31, #32)**:
  - Uninstalling Axiom removes Axiom-owned Windows Firewall rules (`Axiom::`), restores any saved DNS fail-safe baseline, deletes the registered `Axiom` service, cleans up managed AI agent hooks across all 11 supported harnesses, and asks whether to keep or delete saved data (`--remove-data` on CLI) while returning non-zero exit codes if cleanup is only partial.
  - `Axiom.Setup` blocks accidental downgrades over a newer installed desktop or service unless `--allow-downgrade` is passed, removes loose-binary fallback loading beside `Axiom-Setup.exe`, registers per-user Add/Remove Programs uninstall entries (`HKCU`), and validates conflicting CLI switches.
- **Application stability, process safety & tokenized `AgentCommandGuard` (#35, #37)**:
  - Isolates `ConnectionMonitor` UI subscriber exceptions so UI errors cannot stop snapshot updates, and records unhandled startup/UI exceptions to `%LOCALAPPDATA%\Axiom\logs\crash.log`.
  - Captures verified process identity (`ProcessTerminationTarget`: PID, start timestamp, executable path) before Kill confirmations and prevents creating OS firewall block rules against critical system processes (`svchost`, `lsass`, `System`, `launchd`, etc.).
  - Reports `OFFLINE` on Home when the local service is unavailable instead of prematurely showing `READY`.
  - Refactors `AgentCommandGuard` around structured shell-segment tokenization and exact install/data/hook path matching to eliminate false positives on benign commands (commit messages, documentation, searches) while preserving tamper and bypass protections.
- **Strict opt-in privacy, honest wording & instant GitHub Release alerts (#30, #33)**:
  - Sets Blackbox automatic community threat sharing to **unchecked (strict opt-in / off by default)** in both `Axiom.Setup` and First-Run setup.
  - Adds **Settings -> Local data & privacy -> Clear local logs & cache** to delete per-user logs, evidence trails, caches, and crash dumps on demand without touching firewall rules.
  - Aligns [README.md](../../README.md), [PRIVACY.md](../../PRIVACY.md), [docs/SECURITY_MODEL.md](../SECURITY_MODEL.md), [docs/ARCHITECTURE.md](../ARCHITECTURE.md), and Shield dialogs to accurately state Shield behavior, install modes, external endpoints, and data retention.
  - Enables immediate GitHub Release detection on startup (`CheckOnStartupAsync`, bypassing the cooldown while honoring opt-out and dismissed versions), lowers automatic background polling to 30 minutes, and surfaces a desktop alert notification as soon as a new stable version is published.
- **Tray performance & hardened release CI (#34, #36)**:
  - Pauses 1-second connection polling when minimized to the system tray (`_monitor.Stop()` + 30-second protection probe timer) and resumes polling immediately when the window is restored.
  - Pins `.github/workflows/release-packages.yml` actions to verified commit SHAs, adds `v*` tag triggers, and runs all 10 .NET test suites with locked dependencies.
- **Community recognition**:
  - Adds **Special Thanks** in **Settings -> About Axiom**, [README.md](../../README.md), and [AUTHORS.md](../../AUTHORS.md), starting with [@hottogo](https://github.com/hottogo).
