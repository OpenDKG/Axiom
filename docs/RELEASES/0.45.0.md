# Axiom 0.45.0

**Released:** 15 November 2026

0.45.0 wires the F-19 chain into the Windows service: the process-start feed, policy, de-duplication
and JSONL audit sink now run for the service lifetime.

## What this adds

- `ProcessSpawnAuditRuntime` — binds an `IProcessStartSource` to the audit handler, detaches on
  dispose, and is unit-tested with a fake source.
- `ProcessSpawnAuditWorker` (`BackgroundService`, registered in `Program.cs`):
  - opens `%LOCALAPPDATA%\Axiom\process-spawn-audit.jsonl` (append, UTF-8 without BOM, auto-flush);
  - builds the monitor + `JsonLinesProcessSpawnSink` + `WmiProcessStartSource`;
  - resolves executable paths through a `Win32_Process` query, falling back to the trace name;
  - logs start/failure with source-generated `LoggerMessage` and never stops the service if WMI is
    unavailable;
  - disposes the feed and closes the writer on shutdown.

## Verification

- 3 new tests: blocked spawn reaches the sink after start, starting twice does not double-subscribe,
  dispose detaches and disposes the source.
- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- `dotnet test Axiom.sln -c Release --no-build -m:1` — full suite in the release run.
- **Live VM verification is pending install.** WMI subscription only runs when the service starts on
  Windows; the lab VM still has the older build.

## Upgrade notes

Install over 0.44.0. The service starts the feed automatically after upgrade; the audit file appears
on the first recorded child process.
