# Release 0.23.1

Date: 2026-11-14

## Summary

- **Silent module & background execution (no popup console windows)**
  - Added `Axiom.Presentation.AxiomModuleProcessMatcher` (`IsAxiomModuleCommandLine`, `IsDkgCommandLine`, `IsBlackboxCommandLine`) to identify DKG, Blackbox, Hermes plugin, and dashboard helper processes across Windows paths and scripts.
  - Expanded `Axiom.Desktop.Avalonia.Windows.ModuleWindowHider` to honor `BackgroundWindowSettingsStore.Enabled`, match `pythonw.exe`/`cmd.exe`/`powershell.exe`/`pwsh.exe`, fall back to `EnumWindows` + `GetWindowThreadProcessId`, and poll every 500 ms during the first 3 minutes after startup.
  - Added `"hermes"`, `"git"`, and `"pip"` to `BackgroundWindowHider.Names` in `Axiom.Presentation` and `Axiom.UI`, and wired `BackgroundWindowHider.HideDescendants(TimeSpan.FromMinutes(3))` in `Axiom.Desktop/App.xaml.cs`.
  - Updated `OptionalModuleInstaller` (`Axiom.Presentation` and `Axiom.UI`) so `RunPowerShellScript` executes with `UseShellExecute = false`, `CreateNoWindow = true`, `ProcessWindowStyle.Hidden`, redirected standard streams, `-NonInteractive`, thread-safe log forwarding, and `BackgroundWindowHider.HideDescendants(TimeSpan.FromMinutes(10))`; Blackbox startup script exports `$env:BLACKBOX_MODE = 'block'` and `$env:BLACKBOX_ATTACH_ALL = '1'` and prefers `pythonw.exe` when starting the dashboard.
  - Added `SecurityPageViewModel.TryStartInstalledBlackboxOnLaunch` / `PollBlackboxAutoStartAsync` so an already-installed Blackbox module starts silently on launch without user intervention, and updated `OptionalModuleUninstaller` to cleanly remove Antigravity hooks and unregister `'Agent Blackbox dashboard'` alongside `'Agent Blackbox DKG node'`.

- **Complete (`Full`) setup provisioning**
  - Added `Axiom.UI.Services.AntigravityProtection` and updated `Axiom.UI.Services.AgentHookMaintenance` and `SetupInstaller` (`AntigravityProtection`, `ZCodeProtection`, `DeepSeekProtection`) so Complete install provisions and verifies all 11 supported AI agent harnesses.
  - Updated `SetupDefaults.ApplyCompleteAsync` / `WriteUserDefaults` and `PrivacyShieldProvisioner.WriteSettings` to configure `PrivacyShieldProfile.Strict`, all 6 categories (`PrivacyShieldCategories.ForProfile(PrivacyShieldProfile.Strict) | PrivacyCategory.Custom`), all 8 blocklist sources (`PrivacyShieldSourceCatalog.All`), and `CommunityFeedCatalog.RecommendedBundleUrl` with `autoSync = true`.

## Tests

- Added `tests/Axiom.Presentation.Tests/AxiomModuleProcessMatcherTests.cs` (10 positive + 8 negative test cases).
- Extended `tests/Axiom.Presentation.Tests/PrivacyShieldProvisionerTests.cs` to assert `CommunityFeedCatalog.RecommendedBundleUrl` and `autoSync = true` in `community-feed.json`.
- Verified across the full solution test suite (`Axiom.sln`): 926 tests across all 9 test assemblies (`Axiom.Contracts.Tests`: 147, `Axiom.Core.Tests`: 151, `Axiom.Persistence.Tests`: 21, `Axiom.McpServer.Tests`: 33, `Axiom.Presentation.Tests`: 202, `Axiom.UI.Tests`: 174, `Axiom.Service.Tests`: 88, `Axiom.UI.Avalonia.Tests`: 37, `Axiom.Infrastructure.Windows.Tests`: 73).
