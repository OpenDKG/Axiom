# Axiom 0.42.0

**Released:** 15 November 2026

0.42.0 adds the service wiring seam for F-19: a handler the process-start subscription will call,
which applies the policy and de-duplication and forwards only `Record`/`Block` rows to a sink.

## What this adds

- `IProcessSpawnAuditSink` — destination for audit rows (graph writer, UI feed, or a test double).
- `ProcessSpawnAuditHandler`:
  - takes `AgentProcessSpawnMonitor` and a sink;
  - `OnProcessStarted(spawn, allowlist)` returns true only when a row was written;
  - drops allowed children, duplicate observations and allowlisted images;
  - exposes `Recorded` for service metrics.
- No OS subscription yet; the service still needs the ETW/WMI event source.

## Verification

- 4 new tests: blocked staged executable reaches the sink, allowed child dropped, duplicate
  forwarded once, allowlisted image dropped.
- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- `dotnet test Axiom.sln -c Release --no-build -m:1` — full suite in the release run.
- **Live VM verification is pending install**; nothing is subscribed and no rule is written.

## Upgrade notes

Install over 0.41.0. No runtime behaviour change yet.
