# Axiom 0.31.0

**Released:** 15 November 2026

0.31.0 fixes inconsistent row-click / detail-pane selection across Agent Activity, Security Findings, and every other data tab, shrinks `Axiom-Setup.exe` from ~149.7 MB to ~91 MB by removing WPF from Setup and compressing its embedded payload, and ships full release binaries alongside the source tag.

## Highlights

- **Consistent row-click selection across all tabs.**
  - `ListBox.data-list > ListBoxItem` and its `ContentPresenter` now paint a `Transparent` hit-test background with `HorizontalContentAlignment="Stretch"` and zero inter-row dead margins (`AxiomControls.axaml`), and automatically attach `DataListSelection.SelectOnPointerPress="True"`.
  - Switched table row cells in `ConnectionsView`, `EventsView`, `AppsView`, `OverviewView`, `AgentsView` (Verified graph threats), `AiAnalystView`, and `FirewallView` from `AxiomSelectableTextBlock` to `TextBlock` with `Background="Transparent"` on row panels so clicks anywhere in a row select it immediately (while detail panes remain selectable text).
  - Added `DataListSelection.SharedSelectedItem` so grouped `ListBox` controls in `ConnectionsView` and `EventsView` no longer fight over a single ViewModel selection via `TwoWay` bindings.
  - Replaced destructive `.Clear()` rebuilds with `CollectionSync.SyncInPlace` in `AgentsPageViewModel`, `ConnectionsPageViewModel`, `ConnectionAppGroup`, and `EventsPageViewModel`, preserved `SelectedEvent` across `EventsPageViewModel` refreshes, and fixed `AgentsPageViewModel.OnSelectedActivityChanged` skipping refreshes when `HasSelectedActivity` was false.
- **Smaller self-contained installer (`Axiom-Setup.exe`: 149.7 MB -> ~91 MB).**
  - Moved `UpgradeDataGuard` to `Axiom.Contracts.Blackbox`, removed `UseWPF` and the `Axiom.UI` dependency from `Axiom.Setup`, and implemented a DPI-aware dark-mode Win32 installer window (`SetupNativeWindow.cs` + `app.manifest`).
  - Packed `Axiom.Desktop.exe`, `Axiom.Service.exe`, and `community\feed.json` into a compressed `Axiom.Setup.Payload.zip` resource in `scripts/publish-setup.ps1` with `ZipArchive` path-validated extraction in `SetupInstaller.cs`, and enabled partial IL trimming (`PublishTrimmed=true`).
