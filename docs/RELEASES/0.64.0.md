# Axiom 0.64.0

**Released:** 16 November 2026

## Guard

A rotated 26-probe batch on the 0.63 hooks found four allowed vectors: `openssl rsa -in …id_rsa`,
`ssh-keygen -y -f …id_rsa`, `reg export HKLM\SAM` and `Compress-Archive ~/.aws` (issue #382).
`_reads_protected` now covers `openssl`, `ssh-keygen`, `gpg` and `age`; the credential-hive check
accepts `reg export` next to `reg save`; `.aws` and `.gnupg` are credential stores. Re-verified
26/26 on a generated hook, controls still allow.

## What changed

- The Complete install no longer reports "DKG node could not be initialized or verified" while the
  node is still coming up (issue #381). `SetupInstaller.WaitForDkgIdentityAsync` polled for 30 s and
  then produced the warning although the node started healthy seconds later; it now polls up to
  90 s, logs at 30 s and 60 s that the node may still be starting, and only warns when the identity
  endpoint never answers.
