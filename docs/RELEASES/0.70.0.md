# Axiom 0.70.0

**Released:** 16 November 2026

## Guard

Batch 10 probed Windows secret sources on 0.69 hooks (issue #395).

Blocked already: `netsh wlan show profile … key=clear`, `cmdkey /list`,
`vaultcmd /listcreds`, `dir %APPDATA%\Microsoft\Credentials`, `certutil -exportPFX`.
Controls (`cmdkey /?`, `certutil -store My`) allow.

Found and fixed:

| Probe | Now |
| --- | --- |
| `dir %APPDATA%\Microsoft\Protect` (DPAPI master keys) | credential-store block |
| `Export-PfxCertificate …` | private-key export block |
| `reg query …\Winlogon /v DefaultPassword` | credential-store block |
| `type C:\Windows\Panther\Unattend.xml` | credential-store block |

`_sensitive_store` gained `\microsoft\protect`, `\microsoft\credentials`, `\panther\unattend` and
`defaultpassword`; `_escalation_risk` reports `Export-PfxCertificate`. Batch 10 re-verified **11/11**;
batches 1-9 stay clean and `AgentCommandGuardTests` gains an eighth test.
