# Axiom 0.103.0

**Released:** 17 November 2026

## Partner logos are actually readable now

The previous pass raised the image boxes to 124x28 (OriginTrail), 118x22 (Blackbox) and 108x26
(Umanitek), but `Stretch="Uniform"` fits the image inside the box, and the source assets are much
wider than those boxes: OriginTrail is 2170x725 (aspect 3.0) and Umanitek 2172x724, so a 28 px box
rendered them about 84 px wide. That is why they still looked small.

- OriginTrail: box 170x48 (rendered about 143 px wide).
- Blackbox: box 160x28 (the logo is 298x49, so it now fills the width).
- Umanitek: box 144x40 (rendered about 120 px wide).
- The card header keeps the same Grid: logo left, label or partner logo right, no layout change
  beyond the taller logo row.
