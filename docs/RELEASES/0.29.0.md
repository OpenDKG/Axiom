# Axiom 0.29.0

**Released:** 15 November 2026

0.29.0 removes the duplicate Trader Shield panel from the Integrations page (keeping it exclusively in Agent Protection) and trims Windows release packaging bloat by compressing `Axiom.Service.exe` and removing the redundant `Axiom-Setup.exe` copy from the portable ZIP archive.

## Highlights

- **Single Trader Shield panel in Agent Protection (`27a5fa6`).**
  - Removed `<views:TraderShieldSectionView>` and the unused `views` XAML namespace from `SecurityView.axaml`, leaving `AgentsView.axaml` (`Security.TraderShield`) as the single UI location.
  - Added headless Avalonia test `Trader_shield_appears_only_on_agent_protection_and_not_on_integrations` in `TraderShieldSectionViewModelTests`.
- **Release packaging & service compression (`2fa643c`).**
  - Enabled `EnableCompressionInSingleFile=true`, `DebugSymbols=false`, and `AllowedReferenceRelatedFileExtensions=none` for `Axiom.Service` in `scripts/publish-setup.ps1` and `scripts/build-release.ps1` (reducing `Axiom.Service.exe` from `76.74 MB` to `38.59 MB`).
  - Excluded the redundant `Axiom-Setup.exe` copy from `Axiom-<version>-win-x64.zip` (keeping `Axiom-Setup.exe` as its own standalone release asset and reducing the portable archive from `210.52 MB` to `78.22 MB`), and added `-ReusePayload` in `publish-setup.ps1` so `build-release.ps1` publishes Desktop and Service only once.
