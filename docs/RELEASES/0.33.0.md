# Axiom 0.33.0

**Released:** 15 November 2026

0.33.0 hardens the OpenCode/Hermes guard bridge against path and file-operation variants that
passed in a live attack-vector sweep against 0.30.0/0.32.0 (65+ tool calls through the installed
bridge in the Windows 11 lab VM).

## What the sweep found

Blackbox blocks a literal read of a protected path, but these variants were allowed:

- `cat "$HOME/.ssh/id_rsa"`, `type %USERPROFILE%\.ssh\id_rsa`, `type \\?\C:\Users\…\.ssh\id_rsa`
- `move` / `ren` / `Move-Item` / `Rename-Item` of a protected file (delete and copy were blocked)
- `takeown`, `icacls`, `attrib`, `Set-Acl` against a protected file
- `curl --data-binary @…`, `curl -T …`, `wget --post-file=…`, Python `requests.post(...open(key)…)`

## Fixes

- **Path normalization before every protected-path check.** `_normalize_command` expands
  `$HOME`, `${HOME}`, `%HOME%`, `$env:USERPROFILE`, `%USERPROFILE%`, `$env:LOCALAPPDATA`,
  `%LOCALAPPDATA%`, `$env:APPDATA`, `%APPDATA%` and `~/`, then strips the `\\?\`, `//?/` and
  `\\.\` prefixes. `_hits_protected` uses the normalized text.
- **Hidden-path reads.** `_hidden_path_read` blocks a read verb (`cat`, `type`, `Get-Content`,
  `open(`, `.read()`, `copy`, `strings`, …) when the command uses one of those hiding forms and
  references a protected token. A literal `.env.example` read is not affected.
- **Move and rename count as protected-file loss.** `_deletes_protected` now covers `move`,
  `move-item`, `ren`, `rename`, `rename-item`, `mv`.
- **Ownership and ACL tampering.** `_tampers_with_protected` blocks `takeown`, `icacls`, `cacls`,
  `attrib`, `Set-Acl`, `Get-Acl` and `SetAccessRule` against protected paths.
- **More upload shapes.** `--data-binary`, `--upload-file`, `-T`, `requests.post` and `.read()`
  are treated as exfiltration of a protected file.

## Verification

- `dotnet build Axiom.sln --nologo` — 0 warnings, 0 errors across all 21 projects.
- Guard template tests in `AgentHookScriptTests` assert the new detectors exist and run before
  `guard.on_pre_tool_call`.
- Lab VM, 16/16 vectors behave as intended with the 0.33.0 bridge:
  - controls (`echo`, `git status`, allowed write) → **allow**;
  - `$HOME`, `%USERPROFILE%`, `\\?\` reads, `move`/`Move-Item`/`ren`,
    `takeown`/`icacls`/`attrib`, `curl --data-binary`/`-T`, `wget --post-file`, Python POST →
    **block** with a named reason.

## Notes

- The remaining sweep findings (credential dumping, persistence outside CLI, browser credential
  stores, LOLBins, injection phrasings) are tracked for 0.34.0 and later; the prioritized list is
  in the lab log `guard-hardening-backlog.md`.
- No vendor files are modified; this is the Axiom-owned detector layer that runs before the vendor
  guard, like the existing escalation checks.
