# Axiom 1.4.8

- OpenCode V2 and OpenChamber tool calls are now guarded in every workspace: removed the process-wide `globalThis.__axiomBlackboxHooksInstalled` short-circuit in `setup(ctx)` so `ctx.tool.hook("execute.before", ...)` registers on every directory instance and returns a proper disposer, while `IsInstalled` automatically upgrades older `1.4.7` hook plugins.
- Security findings, agent activity, hook evidence, session metadata, network events, Privacy Shield blocked history, and alert records now show exact local `yyyy-MM-dd HH:mm:ss` dates alongside times (including in `Finding details` and clipboard exports).
- Hook evidence on the Agent Stats page now opens a right-side inspector panel on click displaying event metadata and correlated Blackbox findings/activity details (command, path, URL, category, severity, and identifier) for what was evaluated or blocked.
- Consistent `Connected` (green) and `Not connected` / `Offline` (red) status colors across Integrations, Agent Protection, Agent Health, Mini Home, and Settings.
- Moved Trader Shield out of Integrations to the bottom of the Privacy Dashboard.
- The in-app Update popup now fetches and displays multi-line GitHub release notes in a scrollable `What's new` section with a `View on GitHub` link, and Settings -> Updates now includes a manual `Check for updates now` button.
- Extracted a dedicated **Notifications** card in Settings; disabling `Show notifications` suppresses both pop-up alert cards and unread bell-badge counters immediately.
