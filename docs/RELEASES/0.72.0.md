# Axiom 0.72.0

**Released:** 16 November 2026

## Guard

Batch 12 probed password-manager files and a bidi path on 0.71 hooks (issue #399).

Blocked already: AWS SSO cache, AWS CLI config, Bitwarden `data.json`, `.password-store`, a bidi
(`U+202E`) protected path read. The `kdbx-notes.md` control read stays allowed.

Found and fixed:

| Probe | Payload | Now |
| --- | --- | --- |
| KeePass database | `vault.kdbx` | credential-store block |
| 1Password vault | `backup.opvault` | credential-store block |
| Apache htpasswd | `.htpasswd` | credential-store block |

The store markers covered products by directory name but not by file extension, so a database copied
outside its product folder passed. `_sensitive_store` now also matches `.kdbx`, `.opvault` and
`.htpasswd` (leading dot required, so `kdbx-notes.md` and similar notes remain readable).

Batch re-verified **10/10**; batches 1-11 stay clean and `AgentCommandGuardTests` covers the new markers.
