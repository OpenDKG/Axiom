# Axiom 0.32.0

**Released:** 15 November 2026

0.32.0 clarifies the distinction between local Community feed SHA-256 matching and optional online VirusTotal lookups in Integrations → Local file scan, ensures configured community feeds are loaded before matching, and ships full signed-hash release binaries locally and on GitHub.

## Highlights

- **Clearer Community feed vs. VirusTotal (`VT Check`) UX (`SecurityView.axaml`, `SecurityPageViewModel.cs`).**
  - Renamed the row action button from `Check` to `VT Check` with a descriptive tooltip and updated the context menu item to `Check hash on VirusTotal`.
  - Changed initial row status from `"Not checked"` to `"VT: Not checked"` (and `"Skipped"` for skipped files).
  - Updated `ApplyCommunityMatches` and `ScanFilesAsync` to await or load an enabled Community feed if not yet populated, and display a clear neutral notice (`HasScanCommunityNotice`) and `FileScanStatus` reporting exact counts even when 0 community matches are found.
  - Entering a VirusTotal API key via `VT Check` now immediately performs the lookup on that row, and `CreateReputationModule` sets `IsConnected = true` when a VirusTotal key is enabled and present.
