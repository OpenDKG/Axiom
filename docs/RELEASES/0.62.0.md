# Axiom 0.62.0

**Released:** 16 November 2026

0.62.0 introduces **Simple** and **Advanced** UI modes with a one-click **`Simple | Advanced`** switch in the top titlebar beside updates and notifications.

## What changed

- **Simple Mode & Titlebar Switch (`MainWindow`, `ShellViewModel`, `SimpleHomeView`, `UiModeSettingsStore`):**
  - Added a segmented **`Simple | Advanced`** toggle pill directly in the top notification/titlebar (`MainWindow.axaml`) right beside the update and alerts buttons (`UpdateButton`, `AlertsButton`), persisted per user in `%LOCALAPPDATA%\Axiom\ui-mode.txt` (`WindowsUiModeService`).
  - **Simple Mode** focuses the sidebar on five everyday destinations (`Home`, `Network Control`, `Privacy Overview`, `Settings`, `Help & Support`), declutters technical IPC/status-bar badges, and opens **`SimpleHomeView`**: an approachable status hero card (`Turn Shield On` / `Off`), three core summary cards (`Firewall Shield`, `Ad & Tracker Blocker`, `Internet Activity`), inline pending outbound app approvals (`Allow` / `Block`), and active internet apps without technical socket/PID jargon.
  - **Advanced Mode** retains the full 12-page technical dashboard, live graphs, AI agent tools, diagnostics, and status telemetry untouched, automatically switching when deep-linking to Advanced-only views (`NavigateToPage`).
- **Automated coverage (`SimpleAndAdvancedModeTests`):**
  - Added unit tests covering `UiModeSettingsStore` round-trip persistence, default `Simple` mode behavior, live `Simple | Advanced` titlebar switching, sidebar `NavigationPages` updates, and `SimpleHomeView` headless rendering.
