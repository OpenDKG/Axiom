# Axiom 0.89.0

**Released:** 17 November 2026

## Readable partner logos

The OriginTrail, Blackbox and Umanitek marks in the module cards were 92×16–20 px and unreadable on
high-DPI screens. They are now 124×28 (OriginTrail), 118×22 (Blackbox) and 108×26 (Umanitek) inside
the same rounded logo tiles, so the cards keep their layout but the brands read normally.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed on the host and in the lab VM; module cards screenshotted from the installed build.
