# Axiom 1.3.1

- Axiom pauses live chart sampling and full page refreshes while the desktop window is minimized or hidden. Connection monitoring and protection alerts continue in the tray. Leaving an agent page open keeps its Blackbox activity checks running at a lower frequency.
- Integration status uses one polling loop. The interval is 15 seconds with the window open and 60 seconds in the background. Windows console discovery checks for vendor login tasks during the first three minutes.
- Repeated start requests from Axiom share the same pending DKG or Blackbox launch while the port comes up. Repair and cleanup commands enforce a timeout, even if a child process keeps an output stream open.
- Agent Protection shows larger, transparent OriginTrail, Umanitek and Blackbox logos. The marks use a subtle shadow in light themes and wrap on narrow layouts.
