# Axiom 0.21.0

**Released:** 14 November 2026

0.21.0 encrypts Privacy Shield outbound upstream DNS resolution using RFC 8484 DNS-over-HTTPS (DoH) so ISP or on-path observers cannot sniff allowed DNS lookups on UDP/TCP port 53, and expands both Privacy Shield DNS threat lists and public SHA-256 community feeds.

## Highlights

- **RFC 8484 encrypted DNS-over-HTTPS (DoH) upstream (`f11893a`).**
  - Standard public resolvers configured on port 53 (`1.1.1.1`, `1.0.0.1`, `8.8.8.8`, `8.8.4.4`, `9.9.9.9`, `149.112.112.112`, `94.140.14.14`, `94.140.15.15`, plus IPv6 equivalents) automatically upgrade to encrypted `https://<ip>/dns-query` DoH over port `443` with strict no-plaintext-downgrade semantics (`FallbackToPlainAllowed = false`).
  - Explicit `https://.../dns-query` upstream URLs are supported (loopback hosts rejected; bare `/` normalized to `/dns-query`), with direct IP bootstrap sockets (`ConnectCallback`) avoiding loopback recursion when Windows adapters point to `127.0.0.1:53`. Private LAN routers and explicit `udp://` / `tcp://` overrides stay plain DNS.
- **Expanded Privacy Shield Malware & Phishing blocklists (`4055827`).**
  - `PrivacyShieldSourceCatalog.All` expanded from 6 to **8** license-cleared blocklists, adding `hagezi-tif` (HaGeZi Threat Intelligence Feeds Mini, GPL-3.0, commit- and SHA-256-pinned) and `phishing-filter` (OpenPhish / PhishTank / ipthreat domains, MIT) alongside `urlhaus-domains`.
- **Public SHA-256 Community Feed presets & parser (`4055827`).**
  - `CommunityFeedClient` now parses plain-text `#`-commented and CSV SHA-256 lists alongside Axiom JSON feeds, supports multi-URL semicolon/comma deduplication, and surfaces `CommunityFeedCatalog.Presets` in the Community Feed dialog.

## Verification

- Verified across all test suites (`601/601` tests passed at `4055827`, `0` failed, `0` skipped) including RFC 8484 wire format/ID restoration tests, no-plaintext-downgrade tests, catalog tests (`8` sources / `3` Malware lists), and plain-text SHA-256 feed parser tests.

## Upgrade notes

Install over 0.20.0 as usual; existing `1.1.1.1` / `8.8.8.8` / empty-system-DNS configurations automatically encrypt upstream DNS queries over HTTPS/443 without user intervention.
