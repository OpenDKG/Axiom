# Axiom 0.15.0

**Released:** 12 November 2026

0.15.0 splits the mixed dashboard into an agent surface and a network surface. Agent Dashboard is
now the default landing page; Network keeps the connection and throughput view.

## Highlights

- **Agent Dashboard (default).** Sessions, tool calls, blocked and flagged counts, the recorded
  agent activity table with filters and details, and the security findings table. It reuses the
  existing `AgentsPageViewModel`, so the dashboard does not load a second Blackbox audit.
- **Network.** Active sockets, processes, loopback and throughput, followed by the throughput chart,
  new connection events, top applications and live sockets.
- **Navigation.** New **OVERVIEW** group: Agent Dashboard, Network. **MONITORING** starts at Live
  Connections. PROTECTION keeps Agent Protection, Agent Activity, Network Control, Privacy Shield.
- **No behaviour change to enforcement.** The guard, firewall rules, DNS policy and integrations are
  untouched; this release only changes where the UI presents them.
