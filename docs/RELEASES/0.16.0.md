# Axiom 0.16.0

**Released:** 12 November 2026

0.16.0 adds an Agent Health page, renames the network page for consistency, and folds in four
correctness fixes to Network Events, the read-only service surface and the version label.

## Highlights

- **Agent Health (new).** The Protected workspaces card moved out of Agent Protection into its own
  page directly below Agent Activity. It shows the recognized agent workspaces, hook state, runtime
  hook test and the install/repair action. It reuses `SecurityPageViewModel`, so there is one owner
  for the protected-agent probes and timers.
- **Network Dashboard.** The former Network page is now **Network Dashboard**, matching
  **Agent Dashboard**.
- **Network Events write gating (#288).** Block outbound and Block inbound, including their context
  menu entries, are disabled when the service cannot apply firewall changes. The reason is shown
  next to them and the result of the last action stays visible across the 10-second refresh.
- **Accurate empty state (#287).** When a search matches nothing, the page says so instead of
  claiming the service is not running.
- **Read-only `rule.verify` (#277).** `rule.verify` is advertised even when firewall writes are
  disabled; only `rule.apply` and `rule.remove` require the write capability.
- **Version-derived milestone (#278).** The FND-005 label reads the product version, so the service
  and both Settings pages show the same value.

## Upgrade notes

Install over 0.15.0 as usual; settings, the local database and agent hooks are preserved. If the
silent setup reports a non-zero exit code, the desktop is updated but the service helper may have
been skipped; run `%LOCALAPPDATA%\Programs\Axiom\Axiom.Service.exe --install-service` once elevated
to complete the service update.
