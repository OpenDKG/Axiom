# Axiom 1.4.9

- **Three installer modes (`Complete`, `Light`, and `Optional`)**: **Light** installation now configures the Windows service, Axiom Shield firewall (`ask` policy), Privacy Shield encrypted DNS resolver (`53` + DoH `443`, Strict blocklists), Community Threat Feed, notifications, tray protection, and autostart seamlessly out-of-the-box without installing AI agent modules or hooks. A new **Optional** custom mode lets operators toggle each core and AI agent component individually in `Axiom.Setup` or via CLI flags (`--light`, `--complete`, `--optional`, `--with-*/--no-*`), and `scripts/install-from-github.sh` brings matching `--light` / `--complete` / `--optional` setup to Ubuntu 24.04 and Intel macOS.
- **Opt-in `Fail-closed (Strict)` mode and built-in local guard fallback (#26)**: All 11 supported AI agent hooks now enforce Axiom's built-in `AgentCommandGuard` rules (SSH keys, `.env` files, credential stores, crypto wallet paths, tampering, and high-risk shell commands) before contacting Blackbox, so baseline protection remains active even when Blackbox is offline or uninstalled. Operators can also enable **Fail-closed (Strict)** mode on the Agent Protection page (`Guard failure & offline policy`) so unverified tool calls are refused via each host's native deny mechanism (`FAILED_CLOSED`) whenever the guard cannot verify them.
- **Protected security-critical DNS domains (#28, #29) and DoH timeout hardening**: Third-party catalog blocklists can no longer override browser phishing/malware protection (`safebrowsing.googleapis.com`, `safebrowsing.google.com`, `sb-ssl.google.com`, `safebrowsing-cache.google.com`, `shavar.services.mozilla.com`), Microsoft Defender SmartScreen / Windows Update, Windows Push Notification Services (`client.wns.windows.com`, `wns.windows.com`) and NCSI probes, or public CA OCSP/CRL revocation endpoints. `DnsProxyServer` now increases multi-target DoH attempt timeouts (`3.5s` per target / `5s` single upstream) and enables multiple HTTP/2 connections to prevent burst DNS lookup failures.
- **Linux, macOS, and Windows stability improvements (#18, #19, #21, #22, #25)**:
  - macOS `launchd` daemon registers `UnixServicePaths` (`build 26`) so the service starts cleanly without DI composition errors.
  - Ubuntu 24.04 and Intel macOS installers now verify against `SHA256SUMS.txt`, install macOS bundles cleanly to `/Applications/Axiom.app`, and provision pinned Blackbox (`v1.5.0`) + local Oxigraph DKG + agent hooks when `--complete` / `--optional` is selected.
  - Windows Firewall COM calls share a dedicated process-lifetime STA thread to prevent `InvalidComObjectException` when multiple firewall adapter instances are disposed.
- **Full Windows / Linux / macOS parity for OriginTrail DKG, Blackbox, Trader Shield, and Settings**: Removed legacy platform preview limits so Ubuntu 24.04 amd64 and Intel macOS expose First-Run DKG/Blackbox selection, in-app DKG/Blackbox installation/start/repair/stop/uninstall, Trader Shield wallet & seed-phrase protection settings, Glass theme and UI/visual-effects persistence, and consistent AI Agent Guard status reporting.
- Includes an in-app **Privacy Policy** (`PRIVACY.md`) accessible under **Settings -> About Axiom**, matching EU GDPR, Swiss FADP, and US CCPA/CPRA disclosures.
