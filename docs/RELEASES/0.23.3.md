# Release 0.23.3

Date: 2026-11-14

## Summary

- **Full 8-list Privacy Shield rule capacity, malware feed priority, and 3-minute IPC timeout**
  - Raised `PrivacyShieldPolicy.MaxRules` from `500,000` to `1,000,000` so all 8 catalogued lists (including `hagezi-tif` and `phishing-filter`) compile and load together without hitting the combined rule cap.
  - Updated `PrivacyShieldSourceUpdater` to raise `SourceReserve` to `25,000` and import `PrivacyCategory.Malware` feeds first (`hagezi-tif`, `phishing-filter`, `urlhaus-domains`) so bulk ad/tracking lists cannot starve threat-intelligence sources.
  - Raised `IpcCommandTypes.PrivacySourcesUpdate` client timeouts from the default `5s` to `3 minutes` across `Axiom.UI.Avalonia` (`PrivacyShieldPageViewModel`), `Axiom.UI` (`PrivacyShieldViewModel` + `ServicePipeClient`), and `Axiom.Presentation` (`PrivacyShieldProvisioner`).

- **Automatic 24-hour Privacy Shield blocklist updates**
  - Added `AutoUpdateSources` (default `true`, exposed in `PrivacyShieldView.axaml`) and `AutoUpdateIntervalHours` (`24`) to `PrivacyShieldSettings` (`Axiom.Contracts`).
  - Added `PrivacyShieldController.ShouldAutoUpdateSources` and background startup catch-up plus hourly age checks in `PrivacyShieldWorker` so missing or >= 24h stale sources refresh automatically.

- **Seamless adapter DNS persistence across restarts and version upgrades**
  - Added `PreferredAdapterAlias` and `AutoPointAdapterDns` to `PrivacyShieldSettings`.
  - Added `PrivacyDnsFailSafe.EnsureAdapterPointed` (executed inside elevated `LocalSystem` `Axiom.Service` via `PrivacyShieldController.EnsureConfiguredAdapterDns` and `PrivacyShieldWorker`), keeping `127.0.0.1` + previous fallback DNS servers on the chosen or active default-route adapter across reboots, service restarts, and upgrades with no UAC prompt.
  - Enabled `AutoPointAdapterDns = true`, `AutoUpdateSources = true`, and `AutoUpdateIntervalHours = 24` in `SetupDefaults` and `PrivacyShieldProvisioner.CompleteProfileSettings`, and wired `PrivacyShieldPageViewModel` to persist and apply adapter selection through the service first.

- **Cleaner DNS resolver statistics & faster upstream failover**
  - Added `SystemDnsResolver.FilterSystemDnsAddresses` to exclude deprecated Windows IPv6 site-local dummy addresses (`fec0:0:0:ffff::1/2/3`) alongside loopback/unspecified addresses.
  - Updated `DnsProxyServer` to use `MultiTargetAttemptTimeout` (`1,500 ms`) per attempt when multiple upstreams exist (avoiding cascading 3s delays) and stopped counting benign pre-query TCP disconnects as resolver errors.
