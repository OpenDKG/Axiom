# Axiom 0.10.1

**Release date:** 2026-11-09

A small interface fix for 0.10.0: the threat-sharing card now explains what sharing gives back, in a
colour that follows the active palette.

## Change

- The threat-sharing card still explains exactly what Axiom proposes and what it never sends. Under
  that description, a theme-coloured note (success tone on the palette's alternate surface) now says
  that sharing also helps the network: every confirmed indicator strengthens the shared Blackbox
  graph, and a stronger graph helps Axiom and every other node recognise malicious infrastructure
  earlier.
- No behaviour changed: the queue, the honest indicator rules, the 100/day cap and "off means off"
  stay as in 0.10.0.

## Verification

- `dotnet build Axiom.sln`: 0 warnings, 0 errors.
- `dotnet test Axiom.sln`: 466 passed, 0 failed.
- New build installed and started on Windows 11: the note uses the palette's success colour and the
  alternate surface, so it follows Dark, Light, Dark Midnight and Light Warm instead of a fixed
  colour.
