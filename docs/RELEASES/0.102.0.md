# Axiom 0.102.0

**Released:** 17 November 2026

## Export event history as JSON (FND-005)

The Events page could export CSV but not JSON, which left the "bytes/JSON export pending" part of
FND-005 open. The header now has **Export JSON** next to **Export CSV**.

- The export writes the same fields as the CSV: type, application, path, PID, protocol, local and
  remote endpoint, direction, state, quality, and first/last seen in UTC.
- Schema `axiom.network-events.v1`, with `exportedAtUtc` and a row count, indented for diffing.
- It uses the same 5,000-row export limit as CSV and says "(export limit reached)" when the query
  had more rows.
- Read-only: no packet payloads, no bytes (not stored yet), no machine identifiers.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- New `HistoryEventExportTests`: field mapping and the empty-history case.
- Windows CI build, tests and packaging check pass; 0.102.0 installed on host and in the VM.

## Not in this release

Byte counts are still not stored, so the history export cannot include traffic volume. FND-005's
remaining part stays open until the monitor records bytes.
