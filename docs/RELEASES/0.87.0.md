# Axiom 0.87.0

**Released:** 16 November 2026

## Mini fits its content again

- The three overview cards no longer stretch to fill the window: their row is `Auto`, so each card is
  exactly as tall as its numbers.
- Mini opens at 820×560 (minimum 760×430) and the throughput chart is 96 px, so the whole window can
  be shrunk much further while every value stays visible.
- Card padding and value type sizes were tightened for the compact layout.

## Selected buttons

- The selected glass button keeps the slightly lighter background but its text is back to the normal
  light colour — the green text is gone. Unselected buttons stay dark grey with white text.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors.
- Installed on the host and in the lab VM; Mini screenshotted from the installed build.
