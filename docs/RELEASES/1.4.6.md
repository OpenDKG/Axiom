# Axiom 1.4.6

- Windows update notifications display live download progress while fetching and verifying the installer.
- Periodic storage maintenance now runs across Windows, Linux, and macOS desktop hosts, enabling the 512 MiB Oxigraph WAL maintenance threshold on managed DKG configs (including standalone and bundled DKG homes) and retaining a bounded set of rotated DKG and Oxigraph diagnostic logs.
- Oversized diagnostic logs (`agent.log`, `errors.log`, `network-recovery.log`, `tray-error.log`, `start-console.log`) are trimmed in place on newline boundaries while preserving protection history (`findings.jsonl`, `audit.jsonl`) and Hermes dependency environments.
- SQLite history retention checkpoints the WAL (`PRAGMA wal_checkpoint(TRUNCATE)`) and runs a conditional `VACUUM` once substantial free pages accumulate so `axiom.db` reclaims disk space.

## Downloads

- Windows x64 installer and portable ZIP.
- Ubuntu 24.04 amd64 preview package.
- Intel macOS preview app. The archive is ad hoc signed, and the system extension has separate signing and activation requirements.

If your installed build still checks the former private repository, download the installer from [OpenDKG Releases](https://github.com/OpenDKG/Axiom/releases/latest) once to move to the public update channel.
