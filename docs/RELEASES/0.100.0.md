## Preview an exported rule file before it can do anything (FND-008, import half)

0.98.0 added the export. Network Control now also has **Import preview**, which reads a JSON rule
file and validates it with the same `RuleSpecValidator` the write path uses, then reports the
result. It is deliberately **preview only**:

- Nothing is applied, created, imported or changed. There is no write path from the preview.
- The schema must be `axiom.firewall-rules.v1`; other schemas are rejected with a clear message.
- Every entry is checked: GUID, application path (absolute), direction, action, profiles, protocol,
  remote addresses and ports, enabled flag, creator and schema version. Invalid entries are listed
  by their 1-based position with the validator's message.
- Files are capped at 4 MB and 1,000 checked rules so a malformed or huge file cannot stall the UI.
- The status line summarizes e.g. `Import preview: 3 valid rule(s), 1 invalid. Nothing was applied.`

Round-trip tests cover the export → preview path, an unsupported schema, a relative application
path, a missing rule id and malformed input.

## Not in this release

Applying an imported rule stays open. That needs a per-rule confirmation and the existing write
gate; a preview alone must never be mistaken for an import.
