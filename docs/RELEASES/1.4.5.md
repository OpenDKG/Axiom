# Axiom 1.4.5

- AI Analyst labels findings by severity and runs supported OpenCode versions with a dedicated policy that denies access to tools, MCP, plugins, and skills.
- Axiom requests a background Blackbox verified-graph refresh once per hour. Manual refresh remains available.
- Windows maintenance retains a bounded set of rotated DKG and Oxigraph diagnostic logs. Managed Oxigraph nodes receive a 512 MiB WAL maintenance threshold when their config has no threshold. DKG applies this policy when the node starts and can reopen its store during an idle window. Protection history and dependency environments are preserved.
- Update checks and the download button use the public OpenDKG Releases page.

## Downloads

- Windows x64 installer and portable ZIP.
- Ubuntu 24.04 amd64 preview package.
- Intel macOS preview app. The archive is ad hoc signed, and the system extension has separate signing and activation requirements.

If your installed build still checks the former private repository, download the installer from [OpenDKG Releases](https://github.com/OpenDKG/Axiom/releases/latest) once to move to the public update channel.
