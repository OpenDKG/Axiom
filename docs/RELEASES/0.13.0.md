# Axiom 0.13.0

**Release date:** 2026-11-12

This release delivers a complete Antigravity UI/UX overhaul across the Avalonia desktop application,
upgraded Axiom Glass Dark and Light themes, comprehensive right-click context menus and interactive
actions across every page, and hardening fixes for the service-owned network recovery pipeline.

## Highlights

### Antigravity UI/UX Overhaul & Upgraded Glass Themes

- **Antigravity Dark & Light palettes:** Rebuilt `Dark` (Carbon/Zinc `#0B0D11` / `#12151C` with
  `#38BDF8` accent) and `Light` (Studio/Paper `#F6F8FA` / `#FFFFFF` with `#0284C7` accent) for
  crisp hierarchy and high contrast.
- **Upgraded Glass variants:** Refined `Axiom Glass Dark` (Frosted Obsidian) and `Axiom Glass Light`
  (Frosted Pearl) with balanced translucent surfaces, specular border highlights, and readable text.
- **Typography & control system:** Added monospace typography (`Classes="mono"`) for endpoints,
  PIDs, SHA-256 hashes, file paths and timestamps; structured table headers
  (`Classes="table-header"`); and complete control templates for `TextBox`, `ComboBox`, `CheckBox`,
  `ContextMenu`, `MenuItem`, `Button.primary` and `Button.danger`.
- **Modal dialogs:** Updated `AvaloniaUserInteraction`, `FirstRunDialog`, `AvaloniaSecurityDialogs`
  and `AvaloniaBlackboxDialogs` with structured cards and a one-click **Copy Details** button.

### Right-Click Context Menus & Interactive Actions

- **Right-click row selection:** Right-clicking any `ListBoxItem` selects the row before opening
  its context menu.
- **Events & Overview:** Added event inspection dialogs (`Inspect event details`), copying event
  rows/paths/endpoints, blocking outbound/inbound traffic, and terminating processes (`End task`)
  directly from `Events`, `New Connection Markers` and `Top Talkers (5m)`.
- **Connections, Apps, Firewall, Privacy Shield, Security & AI Analyst:** Added structured column
  headers, action toolbars, and context menus for copying endpoints, executable paths, rule details,
  blocked domains and SHA-256 hashes.

### Network Recovery Hardening

- Asynchronous `StandardOutput`/`StandardError` reads in `WindowsDnsRecoveryAdapter.Run` prevent
  pipe deadlocks and enforce the 15-second process timeout.
- Ordered DNS server verification (`SequenceEqual`) in `WindowsDnsRecoveryAdapter` and
  `NetworkRecoveryController` detects swapped primary/secondary DNS servers.
- Reparse-point rejection before reading the recovery snapshot in `NetworkRecoveryCommand.RunAsync`
  and `%ProgramData%\Axiom` ACL hardening after writing the default baseline in
  `NetworkRecoveryController.CaptureNow`.
