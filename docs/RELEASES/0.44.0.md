# Axiom 0.44.0

**Released:** 15 November 2026

0.44.0 adds the Windows process-start feed promised by the F-19 design: a WMI subscription that
turns `Win32_ProcessStartTrace` events into the observations the monitor and audit handler consume.

## What this adds

- `IProcessStartSource` (`Axiom.Core.Enforcement`) — the feed abstraction the service subscribes to.
- `WmiProcessStartSource` (`Axiom.Infrastructure.Windows.ProcessIdentity`):
  - starts a `ManagementEventWatcher` on `Win32_ProcessStartTrace`;
  - extracts process id, parent id and image name;
  - resolves executable paths through an injected resolver (normally a `Win32_Process` lookup),
    falling back to the trace image name when resolution fails;
  - ignores unusable events without stopping the feed;
  - `Dispose` stops and detaches the watcher.
- `Map` is public and pure, so event translation is unit-tested without WMI.

## Verification

## Upgrade notes

Install over 0.43.0. No runtime behaviour change until the service host wires the source.
