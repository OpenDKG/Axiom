# Axiom 0.10.19

**Release date:** 2026-11-11

Threat-sharing values no longer carry URL credentials, query strings or fragments, and the IP
filter now covers the full special-purpose ranges. The README also shows the application for the
first time.

## What was wrong

`ThreatShareVocabulary.Normalize` accepted any `http(s)://` string as-is. A presigned S3/Azure URL,
an `?api_key=`, an OAuth code or `https://user:pass@host` would leave the machine as part of a
report. Loopback and private hosts were also accepted for URLs, because the private-address check
only ran for the `ip` type. On the IP side the filter missed `0.0.0.0/8`, CGNAT, multicast,
documentation and benchmarking ranges, and treated IPv4-mapped IPv6 (`::ffff:192.168.1.10`) as
public.

## What changed

- URLs are parsed with `Uri` and rebuilt from scheme, host, non-default port and path only.
  Userinfo, query and fragment are discarded; IDN hosts are written as punycode.
- A URL host must be a public IP or a dotted public name. `localhost`, `.local`, single-label
  names, loopback, private and special-purpose addresses are rejected.
- `IsNonPublic` now covers:
  - IPv4: this-network, private, CGNAT, loopback, link-local, IETF protocol assignments,
    TEST-NET-1/2/3, AS112/AMT anycast, benchmarking, multicast, reserved and broadcast;
  - IPv6: unspecified, loopback, link-local, site-local, ULA, multicast, IPv4/IPv6 translation,
    discard-only, `2001::/23` protocol assignments, documentation, 6to4, `3fff::/20` and
    `5f00::/16`;
  - IPv4-mapped IPv6 is mapped to IPv4 and checked again.
- `docs/assets/screenshots/overview-dark.png` is added and embedded in the README with a short
  caption. It shows the dark theme, the four live counters and the throughput chart; it contains no
  usernames, local paths or private addresses.

## Verification

- `dotnet build Axiom.sln -c Release`: 0 warnings, 0 errors.
- `dotnet test Axiom.sln -c Release`: 550 passed, 0 failed. `ThreatShareTests` adds URL
  credential/query stripping, IDN, private-host rejection and 24 special-purpose address cases.
- Screenshot captured from the running 0.10.18 desktop after switching to Overview, then cropped
  above the agent-activity table to keep local paths out of the image.
