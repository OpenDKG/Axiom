# Axiom 0.13.1 — Agent Activity Fix, Antigravity Hook/Session Integration & Performance Audit

**Release date:** 2026-11-12  
**Version:** `0.13.1`  
**License:** GPL-3.0-or-later

## Highlights

### 1. Fixed `"No new agent activity since ..."` & Full Antigravity Integration
- **UTF-8 BOM & Windows `cmd.exe` quote fix in `AntigravityProtection`:**
  - Previously, `AntigravityProtection` wrote `~/.gemini/config/hooks.json` with `Encoding.UTF8` (which emits a 3-byte UTF-8 BOM `0xEF 0xBB 0xBF`), causing Antigravity's Go `language_server` to reject `hooks.json` (`invalid character '\ufeff' looking for beginning of value`).
  - Additionally, wrapping paths in double quotes inside `"command"` caused Go's `exec.Command("cmd", "/c", command)` (`syscall.EscapeArg`) to escape quotes as `\"`, which `cmd.exe` rejected.
  - `AntigravityProtection` now writes UTF-8 without BOM (`new UTF8Encoding(false)`), formats the `PreToolUse` command without embedded quotes, automatically repairs existing BOM/quoted `hooks.json` files via `HasOwnedHook()`, invokes `plugins.blackbox.guard.hooks.on_pre_tool_call` in-process, and writes evidence directly to `%LOCALAPPDATA%\Axiom\agent-evidence.jsonl`.
- **Live Antigravity Session Reader (`AgentSessionReader.ReadAntigravity`):**
  - Reads `~/.gemini/antigravity/conversation_summaries.db` and inspects `brain/<id>/.system_generated/logs/transcript.jsonl` and `conversations/<id>.db-wal` timestamps so active Antigravity agent sessions are tracked live alongside Claude Code, Codex, and OpenCode.
- **Accurate Activity Freshness (`ActivityFreshness` & `AgentsPageViewModel`):**
  - Combines timestamps across Blackbox audit events, local hook evidence (`agent-evidence.jsonl`), and active agent sessions (`_agentSessions`).
  - When no agent session is actively running, Axiom reports `"Last agent activity at HH:mm (Xh Ym ago) · no active agent session right now."` (`IsStale = false`) instead of showing a false-positive warning that hooks are broken.
- **Antigravity Hook Probe (`AgentHookProbe`):**
  - Added `"antigravity"` support to `AgentHookProbe.TestAsync` and included Antigravity in `SecurityPageViewModel.InstallAgentHooksAsync`.

### 2. Performance & Code Audit Fixes (Snappy UI, Low CPU & Disk I/O)
- **Incremental Audit Pagination (`AgentsPageViewModel`):**
  - Switching back to `Overview` or `AI Analyst` (`Agents`) now fetches only the newest 1 audit page and merges it via `MergeActivity` instead of resetting `_activityInitialized` and re-fetching 24 pages (up to 12,000 events) over HTTP.
  - `ApplyFilters()` skips clearing and repopulating `Activity` when the filtered sequence is unchanged (`Activity.SequenceEqual(filtered)`).
- **Tail-Read & Caching in `AgentEvidenceStore`:**
  - Replaced full-file `File.ReadLines` every 3 seconds with a 64 KB tail seek (`FileStream.Seek(-65536, SeekOrigin.End)`) and a `(LastWriteTimeUtc.Ticks, Length)` cache.
- **Process Handle & Metadata Caching (`AgentProcessProbe` & `ProcessMetadataProvider`):**
  - Cached `Process.GetProcesses()` process names for 2 seconds and disposed every `Process` instance immediately after reading `ProcessName`.
  - Added `_imageCache` keyed by `(NormalizedPath, LastWriteTimeUtc.Ticks)` in `ProcessMetadataProvider` to avoid repeated synchronous `WinVerifyTrust` Authenticode signature checks and `FileVersionInfo` reads, plus `SeenProcessIds` to avoid repeated WMI `Win32_Process` queries for already-known PIDs.
- **Active-Page Gating & In-Place Collection Updates (`IActivatablePage`):**
  - `OverviewPageViewModel`, `ConnectionsPageViewModel`, `AppsPageViewModel`, and `EventsPageViewModel` implement `IActivatablePage` so inactive tabs defer UI collection work until activated, and update rows in-place when keys match.
- **Service & Adapter Caching (`PrivacyShieldPageViewModel`, `PrivacyShieldBlockedHistoryStore`, `ProtectionSettingsStore`, `ProtectionController`):**
  - Throttled `NetworkInterface.GetAllNetworkInterfaces()` to 15 seconds, cached blocked-domain history and protection settings in memory, and disposed `WindowsIdentity.GetCurrent()` in `ProtectionController`.
