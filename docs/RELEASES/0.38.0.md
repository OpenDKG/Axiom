# Axiom 0.38.0

**Released:** 15 November 2026

0.38.0 adds a real behavioural test for the shared guard helpers: the Python helper block extracted
from `AgentCommandGuard` is executed and 15 vectors are asserted, closing the gap where tests only
checked that strings existed in the template.

## Fixes

- **Behavioural Python test** (`Guard_helpers_block_vectors_in_a_real_python_run`):
  - `_sensitive_store`: `.git-credentials`, Firefox profiles, Chrome `Login Data` → match;
    `notes.txt` → no match.
  - `_hidden_path_read`: `$HOME/.ssh`, `\\?\C:\…\.ssh` → match; `cat notes.txt` → no match.
  - `_tampers_with_protected`: `takeown` on `.ssh` → match; on `C:\Lab\x.txt` → no match.
  - `_escalation_risk`: `reg save HKLM\SAM`, `cmdkey /list` → named labels; `git status` → empty.
  - `_axiom_injection`: "Ignore previous instructions", zero-width variant → match; `git status`
    command → no match.
- The test skips cleanly when Python is unavailable; CI provisions Python 3.12.
