# Code of conduct

This project is a small, technical, open-source effort. Participants are expected to:

- discuss ideas and code, not people;
- give concrete, reproducible technical feedback;
- respect privacy: do not publish other people's logs, paths, IPs, SIDs or personal data;
- avoid harassment, discrimination, threats and spam;
- disclose conflicts of interest when recommending a product or service;
- accept that security claims require evidence and review.

Unacceptable behaviour may lead to comments being removed, contributions being rejected, or access
to the repository being limited. Reports go to the maintainers through the repository's private
channels (for example a GitHub security advisory or a direct maintainer contact listed on the
repository). Reports are handled confidentially.

This policy applies to issues, pull requests, discussions, commit messages and any project space.
