# .NET Library License text

`DOTNET-LIBRARY-LICENSE.txt` is Microsoft's .NET Library License. It is not an Axiom license and is
not covered by Axiom's GPL-3.0-or-later license.

- Source: <https://dotnet.microsoft.com/dotnet_library_license.htm> (redirects to
  `/en-us/dotnet_library_license.htm`)

[`docs/LICENSING.md`](../../../docs/LICENSING.md) for what it covers and what is still open.
